# 题库来源与授权边界

> 适用版本：StudyKit 3.4。本文只谈**内容来源与许可**，不谈抓取技术。
> 许可证会更新，下表写的是核验时的页面口径；正式使用前请以来源页面的最新条款为准。

## 一句话结论

StudyKit **不内置任何真题库**。应用只提供格式、筛选、判分与本地导入；你能导入什么，
取决于你手上那份材料的授权。**“我能打开它”不等于“我能把它打包进 APK 再分发”。**

## 不建议内置或公开再分发的

- **高考/中考真题与解析、考研公共课真题、国考/省考真题**：试卷与解析通常受版权保护，
  机构整理的“答案详解”另有版权。个人学习时自己整理是一件事，打包进 APK、传到网盘、
  发到公开仓库是另一件事。
- **主流出版社教材的配套习题、教师用书、试卷**：即使你买了纸质书，也不等于获得复制与再分发权。
- **机构题库/APP 的截图或导出文件**：界面、题目编排、解析都可能受保护。
- **把“去掉解析里的版权声明”当成获得授权**：不行；删声明不改变权利归属。

## StudyKit 的本地边界

- 应用**纯本地**：导入的文件、生成的方案、练习记录都只留在本机，不上传服务器。
- 但如果你把导入后的题库**导出/分享/重新打包**，责任在分发者，不在应用。
- 内置的 `classic-starter` 示例题库是原创题，仅用于演示格式与阶段×题型覆盖；不包含真题原文。

## 文件导入的边界

支持 `.txt` / `.md` / `.csv` / `.docx` / `.pdf`：

- `.txt`：自动识别 UTF-8（含 BOM）、UTF-16 BOM 与 GBK/GB18030；中文旧编码不会变成乱码。
- `.docx`：读取 `word/document.xml`，还原段落、换行与制表符；公式、图片、批注、页眉页脚不导入。
- `.pdf`：先取文字层；扫描版没有文字层时，用端侧 OCR 识别**前 20 页**，结果需要人工核对。
- `.doc` / `.wps` 旧二进制格式不支持：请用 Word/WPS“另存为” `.docx` 或 PDF。
- 单文件上限 40MB；超限请拆分。

导入的每一行必须是“一行一题、竖线分列”：

```
[阶段·学科·题型] 题干 | 选项A | 选项B | … | 答案 | 解析
[高中·数学·多选] 下列哪些是质数？|2|4|5|9|AC|2 和 5 只有 1 和自身两个因数。
[考公·申论·主观] 题干/材料 | 参考答案 | 评分要点
```

阶段：初中/高中/大学/考研/考公；题型：单选/多选/判断/填空/计算/简答/主观/材料。
格式不对的行会进“待修正”，不会被静默丢掉。

## 五条实操建议

1. **先看许可证，再下载**：优先公版、CC BY、CC BY-NC-SA；看清有没有 **NC**（非商业）和 **SA**（同许可共享）。
2. **只导自己需要的部分**：从整本书里挑 20 道题，比把整本 PDF 塞进来更容易核对，也更不容易踩版权线。
3. **保留来源与署名**：在题干或解析末尾写“来源：OpenStax《College Physics》第 3 章，CC BY 4.0”。
4. **扫描件当草稿**：OCR 只把字送进编辑框，选项/答案的竖线要自己核一遍再导入。
5. **不公开分发别人的题库**：自己刷、自己改可以；要发出去，先确认你有再分发权，或只发原创题。
