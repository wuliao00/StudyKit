# OCR 版面切题与待校对队列（v3.8）

> 本文记录 v3.8 在 v3.7 质量门控/摆正/置信度之上的第二、三阶段：
> 把一页题切成结构化题目、把低置信度/公式风险内容送进人工确认队列、
> 用 300 张合成评测集做 CER 回归。对齐《优化 studykit》文档的
> 「题目结构化」「公式/图形占位」「人工确认闭环」「评测集」四节。

## 1. 规则切题（QuestionLayoutParser）

### 为什么先做规则而不是版面模型

文档建议 YOLOv8n/YOLO11n 版面模型，但训练、模型托管、包体与设备分级都要另起一条工程线。
v3.8 先用「OCR 框 + 正则状态机」把**常见印刷题页**吃下来，零新模型、可单测、可回退；
规则切不出的页仍走题库编辑页，不伪造结构。

### 阅读顺序

1. 过滤页码页脚：纯数字或「第 N 页」，且框落在页面上下 6% 之外；
2. 双栏检测：按框左边界排序，找一条竖分界，要求左侧 >=3 行、右侧 >=3 行、左右空档 > 页宽 12%，
   且右栏起点 > 页宽 30%；命中就先左栏后右栏递归；
3. 单栏：按行聚类（y 方向重叠超过较矮行 60% 算同一行），行内按 x 升序；
4. 任一行没有 OCR 框时退回 OCR 原顺序（det 的 sorted_boxes 已是行序），不硬猜。

### 题目状态机

- 题号开头：1. / 2、/ 2．/ 2) / 第 3 题 / 第 3 题：
- 选项开头：A. / B、/ C．/ D: / (A) 等（A-H）；
- 答案/解析行：答案：/ 参考答案：/ 【答案】/ 解析：/ 【解析】/ 分析：；
- 其余行：有选项时续到最后一个选项，否则续到题干；中文行直接拼、英文行补空格；
- 单行内联选项（A. 4 B. 5 C. 6 D. 9）按标签连续出现拆分，要求标签递增，防误拆普通英文 A./B.；
- 题号行若本身带「题干 + 内联选项」，题干为空时该题不收（没有题干没法复习）。

### v3.10 答案区回填

- 页尾/集中答案区：「答案：1.A 2.B」「参考答案 1-5 ABCDA」「1.A 2.B 3.C 4.D」；
- 有「答案/参考答案」标题且 >=2 组，或单行 >=3 组，判定为答案区；从该行到页尾不参与题干状态机；
- 按题号回填缺答案的题，剩余仍缺的才计入 skippedMissing；
- 区间答案要求字母数 == 题号区间长度，避免「1-3 ABC」长度不符时错配；
- 答案区识别有误判风险：普通题干里出现「3 组题号+字母」会被误判，宁可这页走编辑页兜底。

### 答案映射

| 页面答案 | 落库题型 |
| --- | --- |
| A-H 单个字母（在选项范围内） | 单选 |
| 多个字母（如 AC） | 多选 |
| 正确/错误/对/错/√/×/true/false | 判断 |
| 无选项 + 短答案（<=24 字、无句末标点） | 填空 |
| 无选项 + 长答案 | 简答/主观/材料（参考答案） |
| 缺答案 / 答案格式不认识 | **不自动导入**，计数提示去编辑页补 |

## 2. 待校对队列（Room v13）

### 数据列

questions 新增四列（纯 ADD COLUMN、默认值，老题目不变）：

| 列 | 类型/默认 | 用途 |
| --- | --- | --- |
| needs_review | INTEGER 0 | 1 = 入库后仍需人工确认 |
| ocr_confidence | REAL -1 | OCR 加权平均置信度，-1 = 非 OCR |
| ocr_page_path | TEXT 空 | 来源页相对路径（filesDir/ocr_pages） |
| ocr_layout_json | TEXT {} | 公式提示/页尺寸/警告/行号等 JSON |

### 打标规则

- 拍照/相册（竖线格式）：逐行置信度映射到题目，< 0.85 或照片质量命中 -> needs_review；
  疑似公式行也打标；
- 规则切题：题目置信度 < 0.85 或 formulaHints 非空 -> needs_review；
- 低置信度行同时默认从导入预览剔除（可勾回），两处口径一致：不把疑似错误内容静默写进复习。

### 校对页

- 入口：学习页「待校对题目 N 道」，题库练习前先过一遍；
- 列表显示学科/题型、置信度、题干前 5 行、来源页缩略图、疑似公式提示；
- 动作：确认无误（清 needs_review）、编辑（题干/选项/答案/解析，保存后清标记）、
  删除（题目 + 来源页一起删）、点开原图（整页照片，图形/表格/公式以此为准）；
- 编辑答案解析走 applyReviewEdit（纯函数、单测覆盖）：选择题解析字母，判断题解析正确/错误，
  填空/计算按分号拆可接受答案，简答/主观保留参考答案。

## 3. 公式与图形占位

- FormulaDetector 启发式：数学符号 >=2 且中文占比 <=50%；或有符号且无中文、数字 >=2；
  或无中文、数字 >=2、字母 >=1（短文本）；或化学式/短记号（无空格、字母开头、含数字、<=12 字）；
- 命中行不转 LaTeX，只在 ocr_layout_json 的 formulaHints 里留原文，校对页提示对照原图；
- 来源页整页保存，图形/表格/复杂公式以原图为准；识别错误的普通文本仍可编辑；
- 不接公式识别模型（LaTeX-OCR/RapidFormula/UniMERNet 等），也不把手写公式纳入自动处理。

## 4. 300 张评测集与 CER 回归

- 数据集：tools/ocr_eval/generate_dataset.py，固定种子，300 张 900x1200，八类：
  clear_printed 38 / screenshot 38 / low_light 37 / blur 38 / tilt 37 / two_column 37 / formula 38 / table 37；
- ground_truth.json：每张图的逐行文本与 text；
- OCR 输出：app 的 OcrJvmEvalTest 在宿主 JVM 用桌面版 onnxruntime 跑真模型，输出
  { results: [{id, category, text, lines, confidence, elapsedMs}] }；
- 评估：tools/ocr_eval/evaluate.py 归一化（NFKC、去空白、标点统一）后算逐图 CER（字符级编辑距离 /
  GT 长度）、语料级 CER、分类 mean/P50/P90、CER<=0.05 占比与最差清单；
- 参考结果：300 张合成评测集实测：平均 CER 0.83%（语料级 0.65%）、P50 0%、P90 2.73%、WER 6.47%、空文本 0/300；分类见 docs/evidence/ocr-eval-v3.8.md。
- 复现：
  1. py -3 tools/ocr_eval/generate_dataset.py
  2. gradlew.bat :app:testDebugUnitTest --tests "com.studykit.ocr.eval.OcrJvmEvalTest" -PocrEvalDir=<repo>/tools/ocr_eval -PocrEvalOut=<repo>/tools/ocr_eval/out/ocr_output.json
  3. py -3 tools/ocr_eval/evaluate.py tools/ocr_eval/out/ocr_output.json --out docs/evidence/ocr-eval-v3.8.md

## 5. 已知限制与下一步

- 不透视校正、不弯曲展平；侧拍/厚书弯曲仍靠提示重拍；
- 不用版面模型：跨栏公式、多列表格、图片/图形块仍可能漏切或串行；
- 不识别公式 LaTeX，只提示 + 原图；
- 缺答案题需人工补；当前没有「批量补答案」的多选题操作；
- 评测集是合成页面（字体/排版/退化可控），真实拍照分布仍需用用户样本补充；
- 下一步：透视/去弯曲（纯 Kotlin 或 OpenCV）、版面模型（YOLO 小模型）、公式占位裁剪与
  轻量 LaTeX 模型、评测集扩真实样本、纠错日志沉淀。
