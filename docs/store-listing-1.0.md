# StudyKit 商店文案（1.0 / v3.22）

## 名称
StudyKit

## 副标题
错题本·背单词·打卡

## 一句话
拍一下错题，自动安排复习，完全离线、无广告、开源。

## 短描述（80 字内）
错题本 + 间隔重复 + 背单词 + 打卡。拍一下错题，自动排进复习队列；数据只在本机，离线可用，无账号、无广告。

## 长描述
StudyKit 是一个把「错题本、间隔重复（FSRS）、背单词、打卡」放在一起的纯本地学习应用。

- 拍一下错题：OCR 识别后进复习队列；识别结果可校对、可编辑。
- 自动安排复习：FSRS 根据你的评分排下一次；本机校准你的个人记忆曲线。
- 内置词书：CET-4 / CET-6 / 考研 / 基础词书一键装，离线背。
- 每日 60 秒：签到、复习 5 个词、3 道小测，三步完成今天的启动。
- 完全离线：没有账号、没有上传、没有广告；备份/恢复都在本机。
- 可带走：学习报告/签到/记忆曲线生成分享海报，错题本一键导出 PDF。
