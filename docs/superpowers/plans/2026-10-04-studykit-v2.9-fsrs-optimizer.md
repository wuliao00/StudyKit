# StudyKit v2.9.0 端侧 FSRS 个性化优化器 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在端侧用用户自己的复习记录拟合 FSRS v6（21 参数）记忆曲线，产出可回滚、可评测、过验收门禁才采纳的个性化参数，并让训练出的参数真正流入调度器。

**Architecture:** 纯 Kotlin（本机无 Rust/NDK，放弃文档首选的 JNI 路线，走文档"备选 A"）；把 v6 状态转移抽成单一共享实现 `FsrsModel`，推理（`FsrsKernel`）与训练（`FsrsLearner`）共用，用一条"Double 版 ≡ Dual21 版"测试钉死口径一致；新增 append-only `review_log`（Room v8）作为优化事件流，`param_snapshots` 存快照，活跃参数经 `AppSettings` 注入 `FsrsKernel`。

**Tech Stack:** Kotlin 2.0.21 / Room 2.6.1 KSP（v7→v8）/ Compose / Robolectric 4.14.1（CI 唯一执行器 testDebugUnitTest）/ WorkManager；无新三方依赖（自研 forward-mode autodiff + AdamW）。

package com.studykit.data.memory
import org.junit.Assert.assertEquals
import org.junit.Test
import kotlin.math.pow
class FsrsModelTest {
    private val w = FsrsModel.DEFAULT_PARAMS
    @Test fun `recall matches kernel decay and factor`() {
        // 与 FsrsKernel 同式：DECAY=-w[20], FACTOR=0.9^(1/DECAY)-1
        val decay = -w[20]; val factor = 0.9.pow(1.0/decay) - 1.0
        assertEquals((1.0 + factor*2.0/10.0).pow(decay),
                     FsrsModel.recall(w, stability = 10.0, elapsedDays = 2.0), 1e-12)
    }
    @Test fun `next stability good matches golden 10p96433`() {
        // 取自 fsrs6-golden.json：S=2.3065,D=2.118103970459016,t=2.0,GOOD → S'=10.964332335820698
        val s = FsrsModel.recallStability(w, s = 2.3065, d = 2.118103970459016,
            rr = FsrsModel.recall(w, 2.3065, 2.0), rating = 3)
        assertEquals(10.964332335820698, s, 1e-6)
    }
}
