## 与文档的偏差（有意为之，实现时不要"照文档改回去"）

- **D1 不做 `viz_cache`。** 文档为「10 万卡分箱」准备缓存表，但本仓真实量级是个位数千卡、且 `StatsViewModel` 已经在 `.flowOn(Dispatchers.Default)` 上聚合。加一张表 + 三处失效逻辑去解一个不存在的问题是净负债。若将来真的卡了，再按当次实测数据开一份迁移计划。
- **D2 新词流入摊开而非记在当天。** 文档写 `mean += newPerDay×learningPerNew`（每天 +50），会把负荷带顶成一条常数平台、把「明天会堆积」这个信号彻底抹平。本计划按 `inflowW=[.5,.3,.2]` 把每张新词的学习步摊到引入日及其后两天，**摊开是为了不重复计，不是为了总量守恒**：靠近窗尾的引入日，其 +1/+2 摊派出窗即弃（14 天窗、`newPerDay=10`、`learningPerNew=2.5` 实测合计 332.5 而非 350）。把出窗部分堆到最后一格会凭空造一个假峰，正是 D3 要防的事。
- **D3 到期日出窗即弃。** 文档 `d0=min(horizon−1, round(remain))` 会把所有出窗卡堆到最后一格，凭空造一个假峰。本计划 `round(remain) >= horizon` 直接跳过。
- **D4 提醒时刻用 `initialDelay` 对齐，不申请精确闹钟。** Android 12+ 的 `SCHEDULE_EXACT_ALARM` 需要用户授权且与本仓「不额外要权限」的口径冲突；`PeriodicWorkRequest` 的 `setInitialDelay(到下一个众数小时)` 已能把相位对齐，周期仍由 `reminderEveryHours` 决定。
- **D5 单卡 R 曲线的「到期标记」用 `FsrsModel.nextIntervalDays` 反解**，与调度器同一个函数——这正是文档 ⛔「R 曲线到期标记 == core.interval（全卡遍历断言）」要机检的那件事（Task 7 用真 DAO 数据遍历断言，不写死样例）。

```kotlin
package com.studykit.data.memory

import kotlin.math.max
import kotlin.math.min
import kotlin.math.roundToInt
import kotlin.math.sqrt

/** 一张卡在预测起点上的可见状态。 */
data class ForecastCard(
    /** FSRS v6 稳定度（天）。非有限或 <=0 视为脏数据，被丢弃。 */
    val stabilityDays: Double,
    /** 已落库的到期时刻（epoch ms）。0 = 未排期。预测不吃这一列——见 [DueForecast.forecast] 的 KDoc。 */
    val dueAt: Long,
    /** 距上次复习多少天。 */
    val elapsedDays: Double,
)

/** 负荷带预测的政策参数。 */
data class ForecastCfg(
    val horizonDays: Int = 14,
    /** 目标保留率，来自 `Scheduling.targetRecall`，**不要**在这里写死 0.9。 */
    val retention: Double,
    /** 每日新词 intake（`AppSettings.dailyWordGoal`）。 */
    val newPerDay: Int,
    /** 每张新词随后产生的学习步次数。 */
    val learningPerNew: Double,
    /** 学习步 / 返工在「当天起 +0..+2」三天的摊派权重，和应为 1。 */
    val inflowW: DoubleArray = DEFAULT_INFLOW,
) {
    companion object {
        val DEFAULT_INFLOW = doubleArrayOf(0.5, 0.3, 0.2)
    }
}

/** 窗口里某一天：期望复习数与它的标准差。 */
data class DayBand(val dayIndex: Int, val mean: Double, val sd: Double)

/**
 * 把「已排期卡片的未来轨迹」前推成 N 天负荷带。
 *
 * ## 为什么不用落库的 `dueAt`
 * 到期时刻只反映**上一次评分**排出来的结果；用户今天多评一轮，后面十几天会整体重排。
 * 所以这里由 `S` 与目标保留率**反解**出「还有几天到期」，再叠上已流逝天数：
 * `remain = intervalDays(w, S, R) - elapsed`。这样「今天没练」会如实变成「明天堆积」。
 *
 * ## 三件质量来源
 * 1. **到期本事件**：`mean[d0] += 1`，确定性 → 不贡献方差。
 * 2. **返工**：忘了（概率 `1-R`）的卡会在之后 `+1..+3` 天再回来，按 `inflowW` 摊开；
 *    这一项是伯努利，故同时累加 `p(1-p)·w²` 到方差。
 * 3. **新词学习步**：每天进 `newPerDay` 张，每张产生 `learningPerNew` 次，摊到引入日起 `+0..+2`。
 *
 * 出窗（`round(remain) >= horizon`）的卡**直接跳过**——把它们堆到最后一格会凭空造一个假峰。
 * 脏 `S`（非有限 / <=0）丢弃：宁缺不假。
 */
object DueForecast {

    /** 反解上限：给足，让夹取只由调用方的政策上限决定，而不是被 365 天兜底截断。 */
    private const val REVERSE_CAP_DAYS = 3650.0

    /** 给定 S 与目标保留率，反解「上次复习后第几天到期」。与调度器同一个函数，口径不分叉。 */
    fun intervalDays(w: DoubleArray, stabilityDays: Double, retention: Double): Double =
        FsrsModel.nextIntervalDays(w, stabilityDays, retention, REVERSE_CAP_DAYS)

    fun forecast(cards: List<ForecastCard>, cfg: ForecastCfg, w: DoubleArray = FsrsModel.DEFAULT_PARAMS): List<DayBand> {
        val n = cfg.horizonDays.coerceAtLeast(1)
        val mean = DoubleArray(n)
        val varSum = DoubleArray(n)

        for (card in cards) {
            if (!card.stabilityDays.isFinite() || card.stabilityDays <= 0.0) continue
            val remain = max(0.0, intervalDays(w, card.stabilityDays, cfg.retention) - card.elapsedDays)
            val d0 = remain.roundToInt()
            if (d0 >= n) continue
            mean[d0] += 1.0

            val p = (1.0 - cfg.retention).coerceIn(0.0, 1.0)
            for (k in cfg.inflowW.indices) {
                val d = d0 + 1 + k
                if (d >= n) break
                val weight = cfg.inflowW[k]
                mean[d] += p * weight
                varSum[d] += p * (1.0 - p) * weight * weight
            }
        }

        for (intro in 0 until n) {
            val intake = cfg.newPerDay * cfg.learningPerNew
            if (intro >= n) break
            for (k in cfg.inflowW.indices) {
                val d = intro + k
                if (d >= n) break
                mean[d] += intake * cfg.inflowW[k]
            }
        }

        return (0 until n).map { DayBand(it, min(mean[it], Double.MAX_VALUE), sqrt(max(0.0, varSum[it]))) }
    }
}
```

```kotlin
package com.studykit.data.memory

/** 提醒的三档紧迫度，优先级从高到低。 */
enum class AlertKind { RETENTION_DROP, LOAD_SPIKE, DUE_NOW }

/** 一条要落到通知上的决策。文案在这里定，Worker 只管发。 */
data class ReminderDecision(val kind: AlertKind, val headline: String, val body: String)

/**
 * 该不该提醒、提醒什么。三档优先级：**跌破线 > 堆积 > 到期**。
 *
 * 「跌破线」指某张卡的预测召回已经低于目标保留率再减 [DELTA]——这时候催的不是"到期了"，
 * 而是"你以为还记得，其实已经忘了"，它比任何排期信号都更该打断用户。
 * 「堆积」指明天的期望复习量超过其余天中位数的 [SPIKE_RATIO] 倍（文档 §负荷预测）。
 *
 * 反解一律走 [DueForecast.intervalDays]，与调度器同一个函数：提醒口径和排期口径不能分叉，
 * 否则会出现"通知说有 3 张到期、App 里只列 2 张"。
 */
object ReminderPolicy {

    /** 跌破判定相对目标保留率的下探量。 */
    const val DELTA = 0.05

    /** 明天/其余天中位数 的倍数门槛。 */
    const val SPIKE_RATIO = 1.5

    /** 还有几天到期（负数 = 已经到期）。 */
    fun dueInDays(
        w: DoubleArray,
        stabilityDays: Double,
        retention: Double,
        elapsedDays: Double,
    ): Double = DueForecast.intervalDays(w, stabilityDays, retention) - elapsedDays

    /** 还有几天跌破 `retention - DELTA`（负数 = 已经跌破）。 */
    fun dropInDays(
        w: DoubleArray,
        stabilityDays: Double,
        retention: Double,
        elapsedDays: Double,
    ): Double = DueForecast.intervalDays(w, stabilityDays, (retention - DELTA).coerceAtLeast(0.01)) - elapsedDays

    fun decide(
        cards: List<ForecastCard>,
        bands: List<DayBand>,
        retention: Double,
        todayReviewed: Boolean,
        w: DoubleArray = FsrsModel.DEFAULT_PARAMS,
    ): ReminderDecision? {
        if (todayReviewed) return null
        val usable = cards.filter { it.stabilityDays.isFinite() && it.stabilityDays > 0.0 }
        if (usable.isEmpty() && bands.none { it.mean > 0.0 }) return null

        val dropped = usable.count { dropInDays(w, it.stabilityDays, retention, it.elapsedDays) <= 0.0 }
        if (dropped > 0) {
            return ReminderDecision(
                AlertKind.RETENTION_DROP,
                "有 $dropped 条记忆已经过了线",
                "现在回想起来会吃力，补一次能把它拉回去。",
            )
        }

        spike(bands)?.let { (tomorrow, median) ->
            return ReminderDecision(
                AlertKind.LOAD_SPIKE,
                "明天会堆到 ${tomorrow.roundToInt()} 项",
                "今天先清一点，明天不至于被压住（平时约 ${median.roundToInt()} 项）。",
            )
        }

        val dueNow = usable.count { dueInDays(w, it.stabilityDays, retention, it.elapsedDays) <= 0.0 }
        if (dueNow > 0) {
            return ReminderDecision(
                AlertKind.DUE_NOW,
                "$dueNow 项今天到期",
                "按现在的状态，这些还来得及。",
            )
        }
        return null
    }

    /** 明天是否异常堆积；不异常返回 null。 */
    private fun spike(bands: List<DayBand>): Pair<Double, Double>? {
        if (bands.size < 3) return null
        val tomorrow = bands[1].mean
        val rest = bands.filterIndexed { i, _ -> i != 1 }.map { it.mean }.sorted()
        if (rest.isEmpty() || tomorrow <= 0.0) return null
        val median = if (rest.size % 2 == 1) rest[rest.size / 2] else (rest[rest.size / 2 - 1] + rest[rest.size / 2]) / 2.0
        return if (median > 0.0 && tomorrow > median * SPIKE_RATIO) tomorrow to median else null
    }
}
```

```kotlin
@Composable
fun LoadBandChart(bands: List<DayBand>, capacityPerDay: Int, modifier: Modifier = Modifier) {
    val colors = AppTheme.colors
    val texts = AppTheme.texts
    if (bands.all { it.mean <= 0.0 }) {
        EmptyState("接下来两周没有排期", "评满一轮分之后这里才会画出负荷。")
        return
    }
    Column(modifier = modifier.fillMaxWidth()) {
        Canvas(
            Modifier
                .fillMaxWidth()
                .height(160.dp)
                .semantics { contentDescription = "未来 14 天复习负荷带：实线是期望数量，阴影是波动范围，横虚线是每日容量" },
        ) {
            val peak = (bands.maxOf { it.mean + it.sd } * 1.15).coerceAtLeast(capacityPerDay * 1.15)
            fun x(i: Int) = size.width * (i.toFloat() / (bands.size - 1).coerceAtLeast(1))
            fun y(v: Double) = size.height * (1f - (v / peak).toFloat().coerceIn(0f, 1f))
            // 阴影带 mean±sd：正向描一圈、反向补一圈，构成闭合多边形
            val band = Path().apply {
                moveTo(x(0), y(bands[0].mean + bands[0].sd))
                bands.forEachIndexed { i, b -> lineTo(x(i), y(b.mean + b.sd)) }
                bands.indices.reversed().forEach { i -> lineTo(x(i), y((bands[i].mean - bands[i].sd).coerceAtLeast(0.0))) }
                close()
            }
            drawPath(band, color = colors.accent.copy(alpha = 0.18f))
            drawPath(
                Path().apply { bands.forEachIndexed { i, b -> if (i == 0) moveTo(x(i), y(b.mean)) else lineTo(x(i), y(b.mean)) } },
                color = colors.accent,
                style = Stroke(width = 2.dp.toPx(), cap = StrokeCap.Round),
            )
            // 每日容量线（横虚线）
            drawLine(
                color = colors.divider,
                start = Offset(0f, y(capacityPerDay.toDouble())),
                end = Offset(size.width, y(capacityPerDay.toDouble())),
                strokeWidth = 1.dp.toPx(),
                pathEffect = PathEffect.dashPathEffect(floatArrayOf(8f, 8f)),
            )
            bands.forEachIndexed { i, b ->
                if (b.mean > capacityPerDay) drawCircle(colors.warning, radius = 4.dp.toPx(), center = Offset(x(i), y(b.mean)))
            }
        }
        bands.forEachIndexed { i, b ->
            if (b.mean > capacityPerDay) {
                Text(
                    text = "第 ${i + 1} 天预计 ${b.mean.roundToInt()} 项，超过每日容量 $capacityPerDay 项。",
                    style = texts.caption.copy(color = colors.warning),
                )
            }
        }
    }
}
```
