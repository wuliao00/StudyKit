# StudyKit v3.0-B 考试模式（ramp + 套卷持久化）· 图片遮挡卡 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让「考试」从一个全局日期变成**按学科的清单**，并用它把临窗学科的目标保留率线性提到冲刺值（ramp，⛔ 边界与上限门）；把套卷（模考）从纯内存升级为**可持久、可计时、可暂停、超时自动交卷、未答进待批改**的 `MockSession`；给拍照错题的照片加上**归一化遮挡块**（先回忆、点按再揭），并堵掉今天「重做时照片整张可见 = 印刷答案泄露」这个洞。Room schema **8→9**。

**Architecture:** 四层。① 纯政策层 `data/memory/ExamPolicy.kt` + `MemoryScheduler.forSubject`（零 Android，⛔ 门全在这里跑）；② 存储层：考试清单作为**一项设置**（`app_settings.exams_json`，org.json 数组）而非新表，Room 8→9 只加 `mock_sessions` 表 + `mistakes.kind/extra` 两列；③ 状态机层 `ui/study/MockSessionMachine.kt`（纯函数，复用已审过的 `MockExamState` 判分）+ DAO/Repository 持久化；④ 视图层：`ui/mistake/Occlusion*.kt`（Compose `Canvas` 自绘 + `detectDragGestures`，不引 SVG 库）、遮挡闸接进 `RedoFlow`/`MistakeDetailScreen`。涌量预警复用 v3.0-A 的 `DueForecast`：拿 ramp 之后的目标保留率把关联学科那批卡重跑一遍负荷带，读峰值与中位。

## 与文档的偏差（有意为之，实现时不要"照文档改回去"）

- **D1 遮挡列长在 `mistakes` 上，不是 `cards`。** 文档的 `ALTER TABLE cards ADD COLUMN kind/extra` 假设有统一 `cards` 表 —— **本仓没有**。可复习的实体是 `words` / `questions` / `mistakes` / `excerpts` 四张，其中**只有 `mistakes` 真的存着图片**（`image_path`）。`questions` 没有图片列，且 `ui/bulkimport/QuestionPhotoImport.kt` 导完题会把拍的文件删掉；`words`/`excerpts` 根本没图。所以遮挡卡今天只能是**拍照错题**的扩展。`passage`（段落填空）type 也不做——本仓没有段落型卡片。
- **D2 考试清单是设置项，不是 `exam` 表。** 文档建 `CREATE TABLE exam(...)`。全仓有 8 个读点住在 `AppSettings.examEpochDay` 上（`StudyViewModel:189`、`MistakeViewModel:399`、`StatsViewModel:152`、`ReminderWorker:353`、`StudyHomeScreen:341`、`SettingsViewModel:246`、`SettingsScreen:266-288/463-501`、`Settings.kt` 自身），而设置写入侧是**整份快照 upsert**（`SettingsRepository.save`，加字段零 DAO 改动）。建表会让「考试日」同时住在两个地方：倒计时读设置、ramp 读表 —— 正是 `KernelHub` KDoc 禁止的「两处各说一套」。故 `exams_json` 作为唯一真值，旧键 `exam_epoch_day` **只读不复制**：清单为空时由它合成一场「全学科」考试（`AppSettings.examList`），保持 v2.9 单日期用户的现有行为一字不变。**代价**（接受）：`mock_sessions` 拿不到 `exam_id` 外键，改用 `exam_name` 文本引用，考试改名后旧套卷显示为「未关联考试」。
- **D3 `effectiveRetention` 用 `LocalDate` + `Double`，不是文档的 `today: Long` 毫秒 + `Float`。** 与 `MemoryScheduler.forSettings(strictness, examEpochDay, today: LocalDate)`、`Scheduling(targetRecall: Double, ...)` 同量纲；同一层里不许并存两套时间口径（毫秒/天）与两套精度（Float/Double）。
- **D4 `WorkloadSimulator` 不存在 → 涌量预警复用 `DueForecast.forecast`。** 文档要求「ramp 开启后 WorkloadSimulator 峰值/中位 >2」。v3.0-A 已交付负荷带预测器，这就是那个模拟器；Task 6 只加纯函数 `SprintSurge.peakMedianRatio(bands)` 与阈值 2.0，Task 7 把「同一批关联学科的卡按冲刺保留率重跑一遍负荷带」接上。**不新造第二个预测器。**
- **D5 ramp 只作用于「带学科的卡」。** `words` 没有学科列（只有 `source_list_id`），`excerpts` 归属书。所以 per-subject retarget 落在 `mistakes`（有 `subject`，`MistakeViewModel.gradeRedo` 里学科已在手）与题库侧会话（`QuizUiState.subject`/`MockExamUiState.subject`）；词卡继续走全学科口径（= 那场 `subjects` 为空的考试）。这是数据模型现状，不是策略漏点；「非关联学科恒 base」这条 ⛔ 测试覆盖的正是它。
- **D6 不新增 `ConcealedSection.IMAGE` 枚举值。** `concealed` 是**单值**（一次只能遮一段文字），而图片是与文字**并列**的第二段；塞进同一枚举会造出「遮图片时答案段算不算遮」这种没有正确答案的状态，并留下一个永远与其他值互斥的死值。改为 `RedoGate` 上的投影：`hasImage: Boolean` + `imageVisible: Boolean get() = !(phase == REDO && hasImage)`，效果与文档要求一致（REDO 期间照片不泄露答案），`coveredLabel` 那条文字提示不动。
- **D7 遮挡编辑器只画 rect / ellipse。** 模型、编解码、渲染三型齐全（`rect|ellipse|poly`，往返测试三型都钉），但拖拽建卡侧只出前两型：多边形要「采点 + 闭合」的第二个手势，是另一个交互课题，不塞进本 lane。数据格式先支持，将来加手势不用迁移。
- **D8 模考交卷补双写 `review_log`。** v2.9 起 `review_log` 是参数校准器的唯一训练流，而 `submitMockExam()` 只写 `practice_records`（且不写 confidence）—— 套卷答过的题在训练流里是隐形的。本 lane 要重写交卷（超时自动交卷 / 待批改队列），一并补齐，与背词、练习、错题重做同一口径。
- **D9 交卷后「去建卡」不做题干预填。** 文档 L1883/L1897 要「错题一键进拍照→预览→确认建卡流」。仓里 `addMistakeIfAbsent` **已经**在交卷时自动建了 `source=practice` 的错题（无图）；本计划做的是：结果页给一个按钮跳到既有拍照建卡流并带上学科（新增 `subject` 查询参数），用户在拍摄画面里对着卷子重拍。题干文本预填需要跨页传长文本，收益低（OCR 本来就会把题干拍进去），不做。

`ExamPolicyTest.kt` —— 无 runner 的 JVM 测试，反引号中文测试名：

```kotlin
package com.studykit.data.memory

import java.time.LocalDate
import org.junit.Assert.assertEquals
import org.junit.Assert.assertFalse
import org.junit.Assert.assertNull
import org.junit.Assert.assertTrue
import org.junit.Test

/**
 * `ExamPolicy` 的纯逻辑单测 —— 考试临窗的目标保留率 ramp。
 *
 * 钉的是文档 L1887-1888 那四条 ⛔ 一票否决：边界取值、窗口外、非关联学科、0.97 上限。
 * 全部用固定日期夹具（`TODAY`），不读系统时钟。
 */
class ExamPolicyTest {

    private fun exam(
        day: Long,
        subjects: List<String> = emptyList(),
        sprint: Double = 0.95,
        window: Int = 30,
        name: String = "考试",
    ) = ExamEntry(name = name, epochDay = TODAY.toEpochDay() + day, subjects = subjects, rSprint = sprint, windowDays = window)

    @Test
    fun `硬闸 ramp 边界：窗口起点等于 base`() {
        val e = exam(day = 30L, sprint = 0.95)
        assertEquals(0.80, ExamPolicy.effectiveRetention("数学", TODAY, listOf(e), 0.80), 1e-9)
    }

    @Test
    fun `硬闸 ramp 边界：考试当天等于冲刺值`() {
        val e = exam(day = 0L, sprint = 0.95)
        assertEquals(0.95, ExamPolicy.effectiveRetention("数学", TODAY, listOf(e), 0.80), 1e-9)
    }

    @Test
    fun `硬闸 ramp 边界：窗口外一天不抬`() {
        val e = exam(day = 31L, sprint = 0.95, window = 30)
        assertEquals(0.80, ExamPolicy.effectiveRetention("数学", TODAY, listOf(e), 0.80), 1e-9)
    }

    @Test
    fun `硬闸 非关联学科恒 base`() {
        val e = exam(day = 3L, subjects = listOf("数学"), sprint = 0.95)
        assertEquals(0.80, ExamPolicy.effectiveRetention("英语", TODAY, listOf(e), 0.80), 1e-9)
    }

    @Test
    fun `窗口内线性：中点是半程`() {
        val e = exam(day = 15L, sprint = 0.95, window = 30)
        assertEquals(0.875, ExamPolicy.effectiveRetention("数学", TODAY, listOf(e), 0.80), 1e-9)
    }

    @Test
    fun `硬闸 0.97 上限：冲刺值 0.99 也只到 0.97`() {
        val e = exam(day = 0L, sprint = 0.99)
        assertEquals(ExamPolicy.MAX_EFFECTIVE_RETENTION, ExamPolicy.effectiveRetention("数学", TODAY, listOf(e), 0.80), 1e-9)
    }

    @Test
    fun `base 已高于冲刺值时不往回拉`() {
        val e = exam(day = 0L, sprint = 0.85)
        assertEquals(0.95, ExamPolicy.effectiveRetention("数学", TODAY, listOf(e), 0.95), 1e-9)
    }

    @Test
    fun `多场考试取最紧的那一场`() {
        val far = exam(day = 25L, sprint = 0.90, window = 30)   // 0.80 + 0.10*(1-25/30) = 0.8167
        val near = exam(day = 1L, sprint = 0.96, window = 30)   // 0.80 + 0.16*(1-1/30)  = 0.9547
        // 逐场算完取 max：0.9547 而不是两者的均值或先来后到
        assertEquals(0.9547, ExamPolicy.effectiveRetention("数学", TODAY, listOf(far, near), 0.80), 1e-3)
    }

    @Test
    fun `subjects 为空的那场 = 全学科生效`() {
        val e = exam(day = 0L, subjects = emptyList(), sprint = 0.95)
        assertTrue(ExamPolicy.linksSubject(e, "英语"))
        assertEquals(0.95, ExamPolicy.effectiveRetention("英语", TODAY, listOf(e), 0.80), 1e-9)
    }

    @Test
    fun `subject 为 null 时只吃全学科那场`() {
        val tied = exam(day = 0L, subjects = listOf("数学"))
        val all = exam(day = 0L, subjects = emptyList())
        assertFalse(ExamPolicy.linksSubject(tied, null))
        assertTrue(ExamPolicy.linksSubject(all, null))
        assertEquals(0.80, ExamPolicy.effectiveRetention(null, TODAY, listOf(tied), 0.80), 1e-9)
    }

    @Test
    fun `学科匹配掐空白并忽略大小写`() {
        val e = ExamEntry(name = "J", epochDay = TODAY.toEpochDay(), subjects = listOf(" Math "))
        assertTrue(ExamPolicy.linksSubject(e, "math"))
        assertFalse(ExamPolicy.linksSubject(e, "物理"))
    }

    @Test
    fun `过期考试不参与`() {
        val past = exam(day = -5L, sprint = 0.95)
        assertEquals(0.80, ExamPolicy.effectiveRetention("数学", TODAY, listOf(past), 0.80), 1e-9)
        assertNull(ExamPolicy.nearestExamDaysLeft("数学", TODAY, listOf(past)))
    }

    @Test
    fun `windowDays 为 0 时只在考试当天抬`() {
```

```kotlin
package com.studykit.data.memory

import java.time.LocalDate
import java.time.temporal.ChronoUnit

/**
 * 一场考试（v3.0-B）。住在设置里（`app_settings.exams_json`），不是表 —— 理由见计划 D2：
 * 「考试日」全仓已有 8 个读点在 `AppSettings` 上，另开一张表就是两处真值。
 *
 * [subjects] 为空 = **全学科**。这不是偷懒的默认值，是 v2.9 那个全局考试日的原语义
 * （它当年影响所有卡的排期），旧数据合成进来时必须保持这个口径。
 */
data class ExamEntry(
    val name: String,
    val epochDay: Long,
    val subjects: List<String> = emptyList(),
    val rSprint: Double = DEFAULT_R_SPRINT,
    val windowDays: Int = DEFAULT_WINDOW_DAYS,
) {
    companion object {
        const val DEFAULT_R_SPRINT = 0.95
        const val DEFAULT_WINDOW_DAYS = 30
        const val DEFAULT_NAME = "考试"
    }
}

/**
 * 考试临窗的目标保留率 ramp（文档 §3.3 / L1868-1879）：**政策层**，FSRS 参数一个都不动。
 *
 * `R(t) = R_base + (R_sprint − R_base) · clamp((D0 − t)/D0, 0, 1)`，其中 D0 = [ExamEntry.windowDays]、
 * `D0 − t` 就是剩余天数 [daysLeft]。四个边界是 ⛔ 一票否决（`ExamPolicyTest` 钉着）：
 * left=window → base；left=0 → sprint；left=window+1 → base；非关联学科恒 base。
 *
 * 上限 [MAX_EFFECTIVE_RETENTION] 是护栏：目标保留率往 1 贴，反解出的间隔会坍缩到 0 附近，
 * 复习量随之爆炸（文档 L1877「防间隔坍缩+复习量爆炸」）。
 *
 * 零 Android、零时钟（`today` 由调用方注入），与 [MemoryScheduler] 同量纲（天 + Double）。
 */
object ExamPolicy {

    /** 提升后的目标保留率天花板（⛔ 测试要求 r_sprint=0.99 时结果为 0.97） */
    const val MAX_EFFECTIVE_RETENTION = 0.97

    /**
     * 这场考试管不管这张卡。
     *
     * - `subjects` 为空 = 全学科，连没有学科归属的卡（词卡、书摘）也算；
     * - `subject` 传 `null` = 这张卡没有学科，于是**只**被全学科那场关联（见 [MemoryScheduler.forSubject]）；
     * - 匹配掐首尾空白、忽略大小写：库里 `subject` 是 `SELECT DISTINCT` 来的，用户手输多个空格很常见。
     */
    fun linksSubject(exam: ExamEntry, subject: String?): Boolean {
        if (exam.subjects.isEmpty()) return true
        if (subject == null) return false
        val needle = subject.trim()
        if (needle.isEmpty()) return false
        return exam.subjects.any { it.trim().equals(needle, ignoreCase = true) }
    }

    /** 距考试还有几天（已过为负数，正是「今天考试」= 0 的那个口径） */
    fun daysLeft(exam: ExamEntry, today: LocalDate): Long =
        ChronoUnit.DAYS.between(today, LocalDate.ofEpochDay(exam.epochDay))

    /**
     * 把 base 目标保留率按临窗进度抬到冲刺值，封顶 [MAX_EFFECTIVE_RETENTION]。
     *
     * 多场考试同时命中时取 `max`（= 最紧的那一场），且**只抬不降**：`maxOf` 保证用户已经调严
     * （`STRICT` = 0.95）时，一场冲刺值更低的考试不会反过来把他的复习放松。
     */
    fun effectiveRetention(
        subject: String?,
        today: LocalDate,
        exams: List<ExamEntry>,
        rBase: Double,
    ): Double {
        var r = rBase
        for (exam in exams) {
            if (!linksSubject(exam, subject)) continue
            val left = daysLeft(exam, today)
            if (left < 0L || left > exam.windowDays) continue
            // windowDays<=0 的退化配置：只在当天抬（left 已被上面筛成 0），不做除零
            val progress = if (exam.windowDays <= 0) 1.0 else 1.0 - left.toDouble() / exam.windowDays
            r = maxOf(r, rBase + (exam.rSprint - rBase) * progress)
        }
        return r.coerceAtMost(MAX_EFFECTIVE_RETENTION)
    }

    /** 关联学科里最近一场未来考试的剩余天数；没有未来关联考试 = null（调用方退回默认保持期） */
    fun nearestExamDaysLeft(subject: String?, today: LocalDate, exams: List<ExamEntry>): Int? {
        var best: Long = Long.MAX_VALUE
        for (exam in exams) {
            if (!linksSubject(exam, subject)) continue
            val left = daysLeft(exam, today)
            if (left > 0L && left < best) best = left
        }
        return if (best == Long.MAX_VALUE) null else best.toInt()
    }
}
```

```kotlin
                e.subjects.forEach { subjects.put(it) }

         * 那一项退回默认。整串读不通才退回空表 —— 与 `fromMap` 「脏值只打垮那一项」同一条纪律。

            return try {

                        if (day !in EXAM_DAY_RANGE) continue

                                subjects = buildList {

                                windowDays = o.optInt("windowDays").takeIf { it in EXAM_WINDOW_RANGE } ?: ExamEntry.DEFAULT_WINDOW_DAYS,

                    }
                }
```

```kotlin
    /**
     * 全局口径：取「最近那场考试」算一份 `Scheduling`（不看学科）。
     *
     * 签名一字不改 —— 它今天被 4 个调用点用（学习首页排期初始化、统计预测、复习提醒 worker，
     * 以及错题侧的旧路径），那三处聚合视图**本来就只有一个数字**，不该按学科分裂。
     * 实现收成分派到 [forSubject]：两个入口共用一套算术，杜绝"两处各说一套"。
     *
     * 单个日期在这里摊成一场**全学科**考试（`subjects` 空），即 v2.9 之前的原语义。
     */
    fun forSettings(
        strictness: ReviewStrictness,
        examEpochDay: Long,
        today: LocalDate,
        params: MemoryParams = MemoryParams(),
    ): Scheduling {
        val exams = if (examEpochDay > 0L) listOf(ExamEntry(name = ExamEntry.DEFAULT_NAME, epochDay = examEpochDay)) else emptyList()
        return forSubject(strictness = strictness, exams = exams, subject = null, today = today, params = params)
    }

    /**
     * v3.0-B：某个学科这一轮生效的调度参数 = 「考试 horizon」+「临窗 ramp」。
     *
     * 三段决定，顺序不许换（`ExamPolicyTest` / `MemorySchedulerTest` 分别钉着）：
     *  1. **horizon**：这个学科有没有还没考的未来考试（[ExamPolicy.nearestExamDaysLeft]）。
     *     没有（或 `subject` 传 null 而清单里全是关联学科考试）就退回"要保持半年"那条默认，
     *     于是**英语不会被数学的考试日拖紧** —— 文档「非关联学科不受影响」的字面落地。
     *  2. **base**：`manual ?: targetRecallFor(horizon)`，与旧 `forSettings` 同一式子。
     *  3. **ramp**：[ExamPolicy.effectiveRetention] 在窗口内把 base 线性抬到冲刺值，封顶 0.97。
     *     只抬不降，所以 `STRICT`（0.95）不会被一场低冲刺值的考试反过来放松。
     *
     * `maxIntervalDays` **不进 ramp**：它量的是"这门记忆最多该隔多久"，锚在考试剩余天数上
     * （经验带 ≈1/5 保持期）。目标保留率变严会自动让排出的间隔变短，不需要再削上限；
     * 两头一起收等于对同一个约束罚两次。
     */
    fun forSubject(
        strictness: ReviewStrictness,
        exams: List<ExamEntry>,
        subject: String?,
        today: LocalDate,
        params: MemoryParams = MemoryParams(),
    ): Scheduling {
        val manual = STRICTNESS_TARGET[strictness]
        val days = ExamPolicy.nearestExamDaysLeft(subject, today, exams)
        if (days == null) {
            return Scheduling(
                targetRecall = manual ?: params.defaultTargetRecall,
                maxIntervalDays = MemoryModel.maxIntervalDaysFor(DEFAULT_RETENTION_DAYS, params),
            )
        }
        val base = manual ?: MemoryModel.targetRecallFor(days, params)
        return Scheduling(
            targetRecall = ExamPolicy.effectiveRetention(subject, today, exams, base),
            maxIntervalDays = MemoryModel.maxIntervalDaysFor(days, params),
        )
    }
```

```kotlin
package com.studykit.ui.study

import com.studykit.data.memory.ExamEntry
import com.studykit.data.memory.ExamPolicy
import java.time.LocalDate
import java.time.temporal.ChronoUnit
import kotlin.math.roundToInt

/**
 * 学习首页的考试倒计时那一行（v3.0-B，文档 L1894：`%1$s · 还剩 %2$d 天 · 冲刺保留 %3$.0f%%`）。
 *
 * 文案收在纯函数里才钉得进测试 —— 与 `MistakeScheduling` 尾部那一组 `xxxLine()` 同一手法。
 *
 * 三条口径决定：
 *  - **`rBase` 由调用方传**，而且必须是排期路径上那同一个数（`schedulingForSubject(...).targetRecall`）。
 *    函数自己不猜 base：猜出来的数与真正排期用的那个一分都不一样，屏幕上那句"冲刺保留 90%"
 *    就是一句装饰。参数化之后，页面与调度器不可能分家。
 *  - **「冲刺保留」那一截只在 ramp 真的在生效时出现**：`left < window` 才谈得上被抬过；
 *    `left == window` 时 ramp 给出的就是 base（Task 1 钉死的那条边界），此时印冲刺值是在说一件没发生的事。
 *  - **考试当天保留旧那句「今天考试」**：这五个字从 v2.7 起就在屏幕上，当天再挂一串百分数
 *    不如把它留着（文档那条文案量的是"还剩 N 天"的情形，N=0 时它自己就不成立了）。
 */
internal fun countdownLine(exam: ExamEntry?, today: LocalDate, rBase: Double): String? {
    if (exam == null) return null
    val left = ChronoUnit.DAYS.between(today, LocalDate.ofEpochDay(exam.epochDay))
    if (left == 0L) return "今天考试"
    if (left < 0L) return "「${exam.name}」 已过 ${-left} 天"
    val head = "「${exam.name}」 · 还剩 $left 天"
    if (left >= exam.windowDays) return head
    val effective = ExamPolicy.effectiveRetention(null, today, listOf(exam), rBase)
    return "$head · 冲刺保留 ${(effective * 100).roundToInt()}%"
}
```

`effectiveRetention` 这里传 `subject = null` 是刻意的：这一行讲的是**那场考试整体**的冲刺口径（页面上没有"这一科"的概念）。首页倒计时那一场由 `examForCountdown` 选出，它与 `subjects` 为空的旧式考试同一条读法；真按学科分科的冲刺值差异，用户看的是统计页那条涌量预警（Task 7），不是这一行。

```kotlin
package com.studykit.data.memory

/**
 * 考前涌量预警（v3.0-B，文档 L1891 / L1895）。
 *
 * 文档点名的是「WorkloadSimulator 峰值/中位 >2」。本仓没有那个类，但它存在等价物：
 * v3.0-A 的 [DueForecast.forecast] 就是那台模拟器（负荷带 = 每天要还的卡数分布）。
 * 所以这里只做一个纯读数函数，Task 7 把同一批关联学科的卡按 base / ramped 各跑一遍预测喂进来。
 *
 * 零 Android、零时钟、零 Room。
 */
object SprintSurge {

    /** 报警阈值：文档给的是「>2」，严格大于（恰好 2 倍不吵） */
    const val SURGE_RATIO = 2.0

    /**
     * 峰值 / 中位数。<2 个格子、或中位数为 0（库里几乎没东西可还）时返回 null ——
     * 那种时候算出来的"倍数"是 0 除法产物或无意义的无穷，报出去反而是在骗人。
     */
    fun peakMedianRatio(bands: List<DayBand>): Double? {
        if (bands.size < 2) return null
        val means = bands.map { it.mean }.sorted()
        val median = medianOf(means)
        if (median <= 0.0) return null
        return means.max() / median
    }

    fun shouldWarn(ratio: Double?): Boolean = ratio != null && ratio > SURGE_RATIO

    /** 屏幕上那句话（文档 L1895 的说明 + 实测倍数）；调用方已确认 ratio 非 null */
    fun warningLine(ratio: Double): String =
        "考前这段时间，这科卡片的目标保留率被提到冲刺值，复习量会涨：" +
            "峰值约是中位的 ${"%.1f".format(ratio)} 倍，曲线里能看到涌量。"

    private fun medianOf(sorted: List<Double>): Double {
        val n = sorted.size
        return if (n % 2 == 1) sorted[n / 2] else (sorted[n / 2 - 1] + sorted[n / 2]) / 2.0
    }
}
```

```kotlin
/** 一场考试对它关联学科造成的涌量读数（v3.0-B T7）。 */
data class SprintSurgeState(
    val subject: String,
    val ratio: Double? = null,
) {
    val warn: Boolean get() = SprintSurge.shouldWarn(ratio)
}

/**
 * 拿 ramp 之后的目标保留率把那批卡的负荷带重跑一遍，读峰值与中位（文档 L1891）。
 *
 * 为什么是重跑而不是解析式估：`DueForecast` 里每张卡的到期日是 `nextIntervalDays`
 * **反解**出来的，retention 一变整条分布就平移 —— 想手估峰值就得把那次反解重抄一遍，
 * 而「重抄一遍调度算术」正是本仓反复踩的那个坑（v3.0-A T2.6）。
 *
 * 跑预测用的 `ForecastCfg` 从调用方那份 `cfgBase` copy 出来，只换 `retention`（和需要时的
 * `maxIntervalDays`）：流入参数（`newPerDay`/`learningPerNew`/`inflowW`）一旦与统计页那张图用的
 * 不一致，读出来的涌就有一部分是新词造成的、而不是 ramp 造成的。这条不变式由测试里
 * `horizonDays/newPerDay/learningPerNew/maxIntervalDays 全相等` 那四行钉住。
 *
 * `scheduleOf` 与 `forecast` 都是注入的：前者让本函数零 ViewModel，后者让测试能钉住
 * 「只跑一遍、跑的是冲刺保留率、流入参数照抄页面那份」这三件事（用真预测器写断言会得到一条依赖默认参数的脆测试）。
 *
 * 一场考试只管它那几门：`subjects` 为空 = 全学科那一场，取全部卡；有关联学科时逐科算，
 * **报警取最凶的那一科**（首页只会看到一句提醒）。
 */
internal fun sprintSurgeFor(
    settings: AppSettings,
    cards: () -> List<ForecastCard>,
    cfgBase: ForecastCfg,
    today: LocalDate,
    scheduleOf: (AppSettings, String?, LocalDate) -> Scheduling,
    forecast: (List<ForecastCard>, ForecastCfg) -> List<DayBand> = DueForecast::forecast,
): SprintSurgeState {
    val exams = settings.examList
    if (exams.isEmpty()) return SprintSurgeState(subject = "")
    val all = cards()
    if (all.isEmpty()) return SprintSurgeState(subject = "")
    var worst: SprintSurgeState? = null
    for (exam in exams) {
        val linked: List<String?> = if (exam.subjects.isEmpty()) listOf(null) else exam.subjects.map { it.trim() }
        for (subject in linked) {
            val subset = if (subject.isNullOrEmpty()) all else all.filter { it.subject.equals(subject, ignoreCase = true) }
            if (subset.size < 2) continue
            val base = scheduleOf(settings, subject, today)
            // 单独把"这一场"当唯一考试重算一遍：清单里若还有别的考试在窗内，effectiveRetention
            // 的 max 会把两场的效果掺在一起，读数就不再是"这一场会涌"了。严格度仍取 settings 的那份。
            val ramped = MemoryScheduler.forSubject(settings.reviewStrictness, listOf(exam), subject, today)
            if (ramped.targetRecall <= base.targetRecall) continue   // ramp 没真的抬上去就别跑预测
            val cfgRamp = cfgBase.copy(retention = ramped.targetRecall, maxIntervalDays = ramped.maxIntervalDays)
            val ratio = SprintSurge.peakMedianRatio(forecast(subset, cfgRamp))
            val cur = worst
            if (ratio != null && (cur == null || ratio > (cur.ratio ?: 0.0))) {
                worst = SprintSurgeState(subject = subject ?: ExamEntry.DEFAULT_NAME, ratio = ratio)
            }
        }
    }
    return worst ?: SprintSurgeState(subject = all.firstOrNull { it.subject.isNotEmpty() }?.subject ?: "")
}
```

`MemoryScheduler.forSubject` 的第三个入参是 `subject: String?`，`linked` 里那个 `null`（全学科那场）正好接得上。测试第一例里 `base`（走 `scheduleOf`、看整份清单）与 `ramped`（只看这一场）在**只有一场考试**的夹具上算出的剩余天数相同，所以间隔上限相同、只有 retention 变 —— 夹具里加进第二场考试时这条断言就不再成立，届时按"跑的是冲刺那份 retention、流入照抄页面"重写它，别让它空转。`0.945` 那个期望是手算的（`0.80 + 0.15·(29/30)`），实现给出的若不是它，先自己算一遍再决定改哪边。

```kotlin
package com.studykit.ui.settings

import com.studykit.data.AppSettings
import com.studykit.data.memory.ExamEntry
import java.time.LocalDate
import java.time.format.DateTimeParseException

/**
 * 考试清单编辑器的解析与校验（v3.0-B T9）。全部纯函数、零 Compose，`ExamEditorTest` 直接打。
 *
 * 日期不用 `DatePickerDialog`：本仓从来没有过 Material3 日期选择器（grep `DatePicker` 只命中
 * `Icons.Outlined.DateRange`），既有「考试日」格就是 `yyyy-MM-dd` 文本 + 防抖 + 错误串
 * （`SettingsScreen.kt:266-288`）。清单沿用同一形状，用户在旧格上会的东西到新格上一样会。
 */

/** 一门学科名的长度上限：够写「高等数学（上）」，不够把整题干粘进来 */
private const val SUBJECT_MAX_LEN = 20

/** 一科都塞不下 8 门不叫考试安排，叫抄目录 */
private const val SUBJECT_MAX_COUNT = 8

/** 逗号（半角/全角）、顿号、空白都是分隔符；去空、去重（保留首次出现顺序） */
internal fun examSubjectsFromText(raw: String): List<String> =
    raw.split(',', '，', '、', ' ', '\n', '\t', ';', '；')
        .map { it.trim() }
        .filter { it.isNotEmpty() }
        .map { it.take(SUBJECT_MAX_LEN) }
        .distinctBy { it.lowercase() }
        .take(SUBJECT_MAX_COUNT)

internal fun examSubjectsToText(subjects: List<String>): String = subjects.joinToString("、")

internal data class ExamDraftError(
    val date: String?,
    val sprint: String?,
    val window: String?,
) {
    val hasError: Boolean get() = date != null || sprint != null || window != null
}

/** 解析冲刺值：收 `95`、`94.5` 也收 `0.95`；读不通返回 null */
private fun parseSprint(raw: String): Double? {
    val v = raw.trim().toDoubleOrNull() ?: return null
    return if (v <= 1.0) v else v / 100.0
}

internal fun validateExamDraft(dateText: String, sprintText: String, windowText: String): ExamDraftError {
    val date = dateText.trim().takeIf { it.isNotEmpty() }?.let { raw ->
        runCatching { LocalDate.parse(raw) }.getOrNull()
    }
    val dateError = when {
        date == null -> "按 2026-12-19 这样的 yyyy-MM-dd 填"
        date.toEpochDay() !in AppSettings.EXAM_DAY_RANGE ->
            "日期要在 ${LocalDate.ofEpochDay(AppSettings.EXAM_DAY_RANGE.first)} 到 " +
                LocalDate.ofEpochDay(AppSettings.EXAM_DAY_RANGE.last) + " 之间"
        else -> null
    }
    val sprint = parseSprint(sprintText)
    val sprintError = when {
        sprint == null -> "填 50 到 99 之间的数，或 0.5 到 0.99 之间的小数"
        sprint !in AppSettings.EXAM_SPRINT_RANGE -> "冲刺保留要在 50% 到 99% 之间"
        else -> null
    }
    val window = windowText.trim().toIntOrNull()
    val windowError = when {
        window == null -> "提前多少天开始冲刺，填整数（0=只在考试当天）"
        window !in AppSettings.EXAM_WINDOW_RANGE -> "提前的天数要在 0 到 ${AppSettings.EXAM_WINDOW_RANGE.last} 之间"
        else -> null
    }
    return ExamDraftError(dateError, sprintError, windowError)
}

/**
 * 草稿 -> 条目；任一字段读不通返回 null（调用方就不该把这条写进库）。
 * [fallback] 只用于「编辑已有条目时某格没改动」，新建时传一个占位条目即可。
 */
internal fun examFromDraft(
    name: String,
    dateText: String,
    subjects: List<String>,
    sprintText: String,
    windowText: String,
    fallback: ExamEntry,
): ExamEntry? {
    if (validateExamDraft(dateText, sprintText, windowText).hasError) return null
    val day = LocalDate.parse(dateText.trim()).toEpochDay()
    return ExamEntry(
        name = name.trim().take(40).ifBlank { ExamEntry.DEFAULT_NAME },
        epochDay = day,
        subjects = subjects,
        rSprint = parseSprint(sprintText) ?: fallback.rSprint,
        windowDays = windowText.trim().toIntOrNull() ?: fallback.windowDays,
    )
}

/** 文档 L1895 逐字：`考前 %1$d 天内，这科卡片的目标保留率线性提到冲刺值；复习量会涨，曲线里能看到涌量。` */
internal fun rampHint(windowDays: Int): String =
    "考前 $windowDays 天内，这科卡片的目标保留率线性提到冲刺值；复习量会涨，曲线里能看到涌量。"

/** 文档 L1896 逐字：`定时 %1$d 分钟，暂停%2$s计时。超时未答的题进待批改队列。`（%2$s=也/不） */
internal fun mockTimingHint(limitMin: Int, pauseCounts: Boolean): String {
    val timing = if (limitMin <= 0) "这套卷不限时" else "定时 $limitMin 分钟，暂停${if (pauseCounts) "也照常" else "不照常"}计时"
    return "$timing。超时未答的题进待批改队列。"
}
```

```kotlin
    val colors = AppTheme.colors
    val texts = AppTheme.texts
    var name by rememberSaveable(entry.epochDay) { mutableStateOf(entry.name) }
    var dateText by rememberSaveable(entry.epochDay) { mutableStateOf(LocalDate.ofEpochDay(entry.epochDay).toString()) }
```

```kotlin
package com.studykit.ui.study

import org.json.JSONArray
import org.json.JSONException
import org.json.JSONObject

/**
 * 套卷（模考）的状态机与时限算术（v3.0-B T10，文档 L1883/L1889）。
 *
 * 零 Android、零 Room、零时钟 —— `nowTs` 一律由调用方注入，测试给假时钟即可钉死超时与暂停。
 * 判分**不在这里重写**：那份算术已经在 [MockExamState] 里被 6 条单测钉住，这里只叫它，
 * 然后加它没有的四件事：阶段、截止时刻、暂停是否扣时、未答进待批改。
 *
 * 阶段序号（[MockPhase]）与 `mock_sessions.state` 列的整数**严格对齐**文档 L1861
 * （0 sched 1 run 2 paused 3 grading 4 done）。库里读到对齐不上的整数退回 [MockPhase.SCHED]，
 * 绝不退回 DONE —— 那等于凭空伪造一份"已交卷"的历史（见测试）。
 */
internal enum class MockPhase { SCHED, RUN, PAUSED, GRADING, DONE }

/** 与 `mock_sessions.state` 列的整数一一对应（文档 L1861） */
internal fun encodePhase(phase: MockPhase): Int = when (phase) {
    MockPhase.SCHED -> 0
    MockPhase.RUN -> 1
    MockPhase.PAUSED -> 2
    MockPhase.GRADING -> 3
    MockPhase.DONE -> 4
}

internal fun decodePhase(raw: Int): MockPhase = when (raw) {
    0 -> MockPhase.SCHED
    1 -> MockPhase.RUN
    2 -> MockPhase.PAUSED
    3 -> MockPhase.GRADING
    4 -> MockPhase.DONE
    else -> MockPhase.SCHED
}

/** 到点即到期（`now >= deadline`）。`deadlineTs == null` = 不限时，永不到期 */
internal fun isExpired(nowTs: Long, deadlineTs: Long?): Boolean = deadlineTs != null && nowTs >= deadlineTs

/**
 * 恢复时该把截止时刻定在哪。
 *
 * `pauseCountsTime = true`：暂停也扣时，截止不动（原样返回）。
 * `false`（默认，真实考场的"pause 即停表"）：把暂停掉的那段加回去。
 *
 * 两处下限：暂停时长取负当 0（设备时钟往回跳过不能白送时间）；推出来的截止不能早于现在
 * （早在过去 = 恢复瞬间就"时间到"，那是把用户的剩余时间吃掉而不是停表）。
 */
internal fun deadlineAfterResume(
    nowTs: Long,
    pausedAt: Long,
    deadlineTs: Long?,
    pauseCountsTime: Boolean,
): Long? {
    if (deadlineTs == null) return null
    if (pauseCountsTime) return deadlineTs
    val pausedFor = (nowTs - pausedAt).coerceAtLeast(0L)
    return (deadlineTs + pausedFor).coerceAtLeast(nowTs)
}

internal fun remainingMs(nowTs: Long, deadlineTs: Long?): Long? =
    deadlineTs?.let { (it - nowTs).coerceAtLeast(0L) }

/** 屏幕上那串 `mm:ss`；不限时不给文案（页面就不画那一格） */
internal fun remainingLabel(nowTs: Long, deadlineTs: Long?): String? {
    val ms = remainingMs(nowTs, deadlineTs) ?: return null
    val totalSec = (ms / 1_000L).toInt()
    return "%02d:%02d".format(totalSec / 60, totalSec % 60)
}

/**
 * 一次交卷的产出。
 *
 * - [graded]：答过的那些题的判词（出自 [MockExamState]，与练习/背词同一套算术）；
 * - [toGrade]：**没答**的题（文档 L1883「未答入 grading 队列」）—— 判不了，因为没人给出过选择，
 *   把它们当"答错"是在用 0 冒充一个没发生的事实（`MockExamState` 自己会那么记，这里把那些项摘出去）；
 * - [correctCount] 只统计 [graded]，于是页面上的分母是「判了 N 题」而不是整卷题数。
 */
internal data class MockSubmission(
    val graded: Map<Long, MockExamState.Answer>,
    val toGrade: List<Long>,
    val correctCount: Int,
    val answeredCount: Int,
    val total: Int,
)

internal fun submitOutcome(
    questionIds: List<Long>,
    selections: Map<Long, Int>,
    answerKey: Map<Long, Int>,
    answerCount: Int,
): MockSubmission {
    val machine = MockExamState(questionIds = questionIds, answerCount = answerCount, answerKey = answerKey)
    selections.forEach { (id, selected) -> machine.answer(id, selected) }
    val all = machine.submit()
    val toGrade = questionIds.filterNot { selections.containsKey(it) }
    val graded = all.filterKeys { it !in toGrade.toSet() }
    return MockSubmission(
        graded = graded,
        toGrade = toGrade,
        correctCount = graded.values.count { it.correct },
        answeredCount = graded.size,
        total = questionIds.size,
    )
}

// ── `mock_sessions` 那几个 JSON 列的编解码 ───────────────────────────────
// 读侧一律容错：脏串 -> 空表，而不是抛。这一列可能来自旧版本、也可能来自用户手改的恢复包，
// 与 `AppSettings.fromMap` 同一条纪律。写侧只写自己认得的形状。

internal fun encodeQuestionIds(ids: List<Long>): String {
    val arr = JSONArray()
    ids.forEach { arr.put(it) }
    return arr.toString()
}

internal fun decodeQuestionIds(raw: String): List<Long> {
    if (raw.isBlank()) return emptyList()
    return try {
        val arr = JSONArray(raw)
        buildList {
            for (i in 0 until arr.length()) {
                val v = if (arr.get(i) is Number) arr.getLong(i) else null
                if (v != null) add(v)
            }
        }
    } catch (e: JSONException) {
        emptyList()
    }
}

internal fun encodeAnswers(answers: Map<Long, Int>): String {
    val o = JSONObject()
    answers.forEach { (id, selected) -> o.put(id.toString(), selected) }
    return o.toString()
}

internal fun decodeAnswers(raw: String): Map<Long, Int> {
    if (raw.isBlank()) return emptyMap()
    return try {
        val o = JSONObject(raw)
        buildMap {
            val keys = o.keys()
            while (keys.hasNext()) {
                val k = keys.next()
                val id = k.toLongOrNull() ?: continue
                val v = if (o.get(k) is Number) o.getInt(k) else null
                if (v != null) put(id, v)
            }
        }
    } catch (e: JSONException) {
        emptyMap()
    }
}

internal fun encodeResults(results: Map<Long, MockExamState.Answer>): String {
    val o = JSONObject()
    results.forEach { (id, a) ->
        o.put(id.toString(), JSONObject().put("s", a.selected ?: JSONObject.NULL).put("c", if (a.correct) 1 else 0))
    }
    return o.toString()
}

internal fun decodeResults(raw: String?): Map<Long, MockExamState.Answer> {
    if (raw.isNullOrEmpty() || raw == "{}") return emptyMap()
    return try {
        val o = JSONObject(raw)
        buildMap {
            val keys = o.keys()
            while (keys.hasNext()) {
                val k = keys.next()
                val id = k.toLongOrNull() ?: continue
                val v = o.optJSONObject(k) ?: continue
                val selected = if (v.isNull("s")) null else v.optInt("s", -1).takeIf { it >= 0 }
                put(id, MockExamState.Answer(selected = selected, correct = v.optInt("c") == 1))
            }
        }
    } catch (e: JSONException) {
        emptyMap()
    }
}

internal data class MockSummary(val correctCount: Int, val total: Int, val toGrade: List<Long>)

internal fun encodeExamResult(out: MockSubmission): String =
    JSONObject()
        .put("correct", out.correctCount)
        .put("total", out.total)
        .put("graded", out.answeredCount)
        .put("toGrade", JSONArray().apply { out.toGrade.forEach { put(it) } })
        .toString()

/** 摘要读不通返回 null（宁缺一条分数，不显示一个 0 分的假成绩） */
internal fun decodeExamResult(raw: String?): MockSummary? {
    if (raw.isNullOrEmpty()) return null
    val o = try { JSONObject(raw) } catch (e: JSONException) { return null }
    if (!o.has("total")) return null
    return MockSummary(
        correctCount = o.optInt("correct"),
        total = o.optInt("total"),
        toGrade = o.optJSONArray("toGrade")?.let { arr ->
            buildList { for (i in 0 until arr.length()) arr.optLong(i).takeIf { it > 0L }?.let { add(it) } }
        } ?: emptyList(),
    )
}
```

```kotlin
    /**
     * 防抖落库：取消上一条还没起跑的写，再写**当前**这一份。
     *
     * 为什么不逐次写：一次连点四道题会排四个 `launch`，它们读到的 `mockSessionRow` 有可能不是
     * 同一个版本，最后落库的不一定是最新的那份。取消重排让"在途的写"最多一条，且一定是最新的快照。
     *
     * 代价：进程恰好在防抖窗口内被杀，最多丢 400ms 内的作答 —— 记在这里，不假装它不存在。
     */
    private fun persistMockSession(patch: (MockSession) -> MockSession) {
        val base = mockSessionRow ?: return
        val next = patch(base)
        mockSessionRow = next
```

```kotlin
package com.studykit.ui.mistake

import com.studykit.data.entity.Mistake
import org.json.JSONArray
import org.json.JSONException
import org.json.JSONObject

/**
 * 图片遮挡块（v3.0-B，文档 L1884：`extra.shapes = [{t:rect|ellipse|poly, 归一化坐标 0-1}]`）。
 *
 * 坐标全部归一化到 0..1：照片的像素尺寸随拍摄设备与 `MistakeImageStore` 的长边压缩
 * （1600px）而变，只有比例在「画的那次」和「看的那次」之间成立。
 *
 * `kind` 是唯一开关：`Mistake.KIND_OCCLUSION` 才承认 `extra` 里的形状，`KIND_BASIC` 一律当普通卡。
 * 理由是要一条能一眼看穿的规则 —— 万一 `extra` 里躺着脏数据（旧备份恢复、手工改库），
 * 判断不能靠"形状数组非空"这种间接证据，否则一张普通错题会凭空变成遮挡卡。
 *
 * 读侧逐条容错（与 `AppSettings.fromMap`、`shapesFromJson` 的兄弟 `parseOptions` 同纪律）：
 * 单条读不通丢那条，整串读不通丢全表，绝不抛。
 */
internal sealed interface OcclusionShape {

    /** 归一化左上/右下（写入前已保证 left<=right、top<=bottom） */
    data class Rect(val left: Double, val top: Double, val right: Double, val bottom: Double) : OcclusionShape()

    data class Ellipse(val centerX: Double, val centerY: Double, val radiusX: Double, val radiusY: Double) : OcclusionShape()

    /** 至少 3 个点（少于 3 个不构成多边形，读侧直接丢） */
    data class Polygon(val points: List<NormalizedPoint>) : OcclusionShape()
}

internal data class NormalizedPoint(val x: Double, val y: Double)

/** 短于这个比例的块多半是误触（照片长边 1600px 时约等于 3px） */
private const val MIN_EXTENT = 0.005

/** `t` 字段用的三个 token，与文档 L1884 一致；`poly` 不写成 `polygon`（文档拼法为准） */
private const val TYPE_RECT = "rect"
private const val TYPE_ELLIPSE = "ellipse"
private const val TYPE_POLY = "poly"

private fun clamp01(v: Double): Double = if (v.isNaN()) 0.0 else v.coerceIn(0.0, 1.0)

internal val OcclusionShape.centerU: Double
    get() = when (this) {
        is OcclusionShape.Rect -> (left + right) / 2
        is OcclusionShape.Ellipse -> centerX
        is OcclusionShape.Polygon -> points.sumOf { it.x } / points.size
    }

internal val OcclusionShape.centerV: Double
    get() = when (this) {
        is OcclusionShape.Rect -> (top + bottom) / 2
        is OcclusionShape.Ellipse -> centerY
        is OcclusionShape.Polygon -> points.sumOf { it.y } / points.size
    }

internal fun shapesToJson(shapes: List<OcclusionShape>): String {
    val arr = JSONArray()
    shapes.forEach { s ->
        val o = when (s) {
            is OcclusionShape.Rect -> JSONObject().put("t", TYPE_RECT).put("l", s.left).put("t2", s.top).put("r", s.right).put("b", s.bottom)
            is OcclusionShape.Ellipse -> JSONObject().put("t", TYPE_ELLIPSE).put("cx", s.centerX).put("cy", s.centerY).put("rx", s.radiusX).put("ry", s.radiusY)
            is OcclusionShape.Polygon -> JSONObject().put("t", TYPE_POLY).put(
                "pts",
                JSONArray().apply { s.points.forEach { p -> put(JSONObject().put("x", p.x).put("y", p.y)) } },
            )
        }
        arr.put(o)
    }
    return JSONObject().put("shapes", arr).toString()
}

internal fun shapesFromJson(raw: String): List<OcclusionShape> {
    if (raw.isBlank()) return emptyList()
    return try {
        val arr = JSONObject(raw).optJSONArray("shapes") ?: return emptyList()
        buildList {
            for (i in 0 until arr.length()) {
                val o = arr.optJSONObject(i) ?: continue
                when (o.optString("t")) {
                    TYPE_RECT -> {
                        val l = clamp01(o.optDouble("l"))
                        val r = clamp01(o.optDouble("r"))
                        val t = clamp01(o.optDouble("t2"))
                        val b = clamp01(o.optDouble("b"))
                        if (r - l >= MIN_EXTENT && b - t >= MIN_EXTENT) {
                            add(OcclusionShape.Rect(minOf(l, r), minOf(t, b), maxOf(l, r), maxOf(t, b)))
                        }
                    }
                    TYPE_ELLIPSE -> {
                        val rx = o.optDouble("rx")
                        val ry = o.optDouble("ry")
                        if (rx.isFinite() && ry.isFinite() && rx >= MIN_EXTENT && ry >= MIN_EXTENT) {
                            add(OcclusionShape.Ellipse(clamp01(o.optDouble("cx")), clamp01(o.optDouble("cy")), rx.coerceAtMost(1.0), ry.coerceAtMost(1.0)))
                        }
                    }
                    TYPE_POLY -> {
                        val pts = o.optJSONArray("pts")
                        val list = buildList {
                            if (pts != null) {
                                for (j in 0 until pts.length()) {
                                    val p = pts.optJSONObject(j) ?: continue
                                    add(NormalizedPoint(clamp01(p.optDouble("x")), clamp01(p.optDouble("y"))))
                                }
                            }
                        }
                        if (list.size >= 3) add(OcclusionShape.Polygon(list))
                    }
                }
            }
        }
    } catch (e: JSONException) {
        emptyList()
    } catch (e: NullPointerException) {
        emptyList()
    }
}

/** 这张错题上画了哪些遮挡块；`kind != KIND_OCCLUSION` 一律空表（见类注释那条开关规则） */
internal fun occlusionShapes(mistake: Mistake): List<OcclusionShape> =
    if (mistake.kind == Mistake.KIND_OCCLUSION) shapesFromJson(mistake.extra) else emptyList()

```

```kotlin
internal data class RedoGate(
    val phase: RedoPhase,
    val stemText: String,
    val answerKey: String,
    val noteText: String,
    val concealed: ConcealedSection,
    /** 这一条错题有没有随附照片（`image_path` 非空且文件真的在） */
    val hasImage: Boolean = false,
    /** 照片上画了几处遮挡块（0 = 没画） */
    val shapeCount: Int = 0,
) {
    val hasReveal: Boolean get() = concealed != ConcealedSection.NONE
    val isCovered: Boolean get() = phase == RedoPhase.REDO && hasReveal
    val answerKeyVisible: Boolean get() = !(phase == RedoPhase.REDO && concealed == ConcealedSection.ANSWER_KEY)
    val noteVisible: Boolean get() = !(phase == RedoPhase.REDO && concealed == ConcealedSection.NOTE)

     * 重做阶段照片该不该整张扣住。
     *
     * **画了遮挡块 = 用户已经指明答案写在哪几块**，那剩下的部分本来就不含答案，可以放心看；
     * **没画 = 我们不知道答案在照片哪里**，于是整张扣到核对阶段。

    val partiallyCovered: Boolean get() = hasImage && shapeCount > 0 && phase == RedoPhase.REDO
}

internal fun buildRedoGate(
    content: String,
    note: String,
    phase: RedoPhase,
    hasImage: Boolean = false,
    shapeCount: Int = 0,
): RedoGate {
    val split = splitForRedo(content)
    val concealed = when {
        split.answerKey.isNotBlank() -> ConcealedSection.ANSWER_KEY
        note.isNotBlank() && !isMachineNote(note) -> ConcealedSection.NOTE
        else -> ConcealedSection.NONE
    }
    return RedoGate(
        phase = phase,
        stemText = split.stem,
        answerKey = split.answerKey,
        noteText = note,
        concealed = concealed,
        hasImage = hasImage,
        shapeCount = shapeCount.coerceAtLeast(0),
    )
}
```

```kotlin
/**
 * 照片 + 遮挡块 + 点按全揭（v3.0-B T15）。
 *
 * 渲染是**一个 Canvas**（文档 L1884「单 View 自绘，不引 SVG 库」）：图在下、罩在上，
 * 罩的几何全部由 [shapePixelRect] 从归一化坐标换算，`Canvas` 里按类型分派 drawRect/drawOval/drawPath。
 *
 * 揭开是**整层一起揭**（`onRevealAll`），不做"逐块点揭"：逐块点按要先证明用户点的是块而不是图，
 * 而这一块屏上本来就只有一张图和一层罩子，猜错一次的代价是把答案亮出来。
 * 语义与 `RedoGate` 那条一致：先回忆，再揭。
 */
@Composable
internal fun OcclusionImage(
    model: File,
    shapes: List<OcclusionShape>,
    modifier: Modifier = Modifier,
    onRevealAll: (() -> Unit)? = null,
    revealed: Boolean = false,
) {
    val colors = AppTheme.colors
    val covering = shapes.isNotEmpty() && !revealed && onRevealAll != null
    Box(
        modifier = modifier
            .fillMaxWidth()
            .clip(RoundedCornerShape(AppTheme.radius.lg))
            .border(width = 1.dp, color = colors.divider, shape = RoundedCornerShape(AppTheme.radius.lg)),
    ) {
        AsyncImage(
            model = model,
            contentDescription = "错题照片",
            contentScale = ContentScale.FillWidth,
            modifier = Modifier.fillMaxWidth(),
        )
        if (covering) {
            Canvas(
                modifier = Modifier
                    .matchParentSize()
                    .semantics { contentDescription = "遮住答案，点按全揭" }
                    .pointerInput(shapes) { detectTapGestures { onRevealAll() } },
            ) {
                shapes.forEach { s ->
                    val r = shapePixelRect(s, size.width, size.height)
                    when (s) {
                        is OcclusionShape.Rect -> drawRect(color = colors.lightbox, topLeft = r.topLeft, size = r.size)
                        is OcclusionShape.Ellipse -> drawOval(color = colors.lightbox, topLeft = r.topLeft, size = r.size)
                        is OcclusionShape.Polygon -> {
                            val path = Path().apply {
                                val pts = s.points
                                moveTo(pts.first().x.toFloat() * size.width, pts.first().y.toFloat() * size.height)
                                pts.drop(1).forEach { p -> lineTo(p.x.toFloat() * size.width, p.y.toFloat() * size.height) }
                                close()
                            }
                            drawPath(path, color = colors.lightbox)
                        }
                    }
                }
            }
        }
    }
}

/** 归一化 -> 像素。宽高各走自己的轴（照片不是正方形时这是唯一正确的读法）。纯算术，单独钉 */
internal fun shapePixelRect(shape: OcclusionShape, widthPx: Float, heightPx: Float): Rect = when (shape) {
    is OcclusionShape.Rect -> Rect(
        left = (shape.left * widthPx).toFloat(),
        top = (shape.top * heightPx).toFloat(),
        right = (shape.right * widthPx).toFloat(),
        bottom = (shape.bottom * heightPx).toFloat(),
    )
    is OcclusionShape.Ellipse -> Rect(
        left = ((shape.centerX - shape.radiusX) * widthPx).toFloat(),
        top = ((shape.centerY - shape.radiusY) * heightPx).toFloat(),
        right = ((shape.centerX + shape.radiusX) * widthPx).toFloat(),
        bottom = ((shape.centerY + shape.radiusY) * heightPx).toFloat(),
    )
    is OcclusionShape.Polygon -> {
        val xs = shape.points.map { it.x * widthPx }
        val ys = shape.points.map { it.y * heightPx }
        Rect(xs.min(), ys.min(), xs.max(), ys.max())
    }
}
```

```kotlin
internal enum class EditorShape { RECT, ELLIPSE }

private const val MIN_DRAG = 0.01   // 归一化下 1% 以内当误触

/**
 * 一次拖拽 -> 一个遮挡块。坐标必须已经归一化（0..1），composable 那边负责除以视图宽高。
 * 返回 null = 这块不该存在（太小或夹不出来），调用方直接忽略这次拖拽。
 */
internal fun dragToShape(startU: Double, startV: Double, endU: Double, endV: Double, type: EditorShape): OcclusionShape? {
    val l = minOf(startU, endU).coerceIn(0.0, 1.0)
    val r = maxOf(startU, endU).coerceIn(0.0, 1.0)
    val t = minOf(startV, endV).coerceIn(0.0, 1.0)
    val b = maxOf(startV, endV).coerceIn(0.0, 1.0)
    if (r - l < MIN_DRAG || b - t < MIN_DRAG) return null
    return when (type) {
        EditorShape.RECT -> OcclusionShape.Rect(l, t, r, b)
        EditorShape.ELLIPSE -> OcclusionShape.Ellipse((l + r) / 2, (t + b) / 2, (r - l) / 2, (b - t) / 2)
    }
}

/**
 * 拖拽画罩（文档 L1884「建卡编辑器拖拽加罩」，手势手法照 `ui/habit/SnakeBoard.kt:132-157`）。
 *
 * 只出矩形与椭圆两型（计划 D7）：多边形要"采点 + 闭合"的第二手势，数据格式已经支持，
 * 加手势时不用动迁移。
 *
 * 无图时整块不出现 —— 「先拍一张」的引导由调用方给（`MistakeCaptureScreen` 里已经有 `captured` 那一段）。
 */
@Composable
internal fun OcclusionEditor(
    photo: File,
    shapes: List<OcclusionShape>,
    type: EditorShape,
    onTypeChange: (EditorShape) -> Unit,
    onAdd: (OcclusionShape) -> Unit,
    onUndo: () -> Unit,
    onClear: () -> Unit,
    modifier: Modifier = Modifier,
) {
    var dragStart by remember { mutableStateOf<Offset?>(null) }   // 视图内像素坐标
    var dragCurrent by remember { mutableStateOf<Offset?>(null) }
    var viewSize by remember { mutableStateOf(IntSize.Zero) }
    val colors = AppTheme.colors
    val texts = AppTheme.texts
    // 拖拽中的那块先在本地算出来：Canvas 的 content 是带接收者的 lambda，里面不能非局部 return，
    // 所以"算不出就不画"这件事必须在进 Canvas 之前决定。
    val liveShape = remember(dragStart, dragCurrent, viewSize, type) {
        val a = dragStart
        val b = dragCurrent
        if (a == null || b == null || viewSize.width <= 0 || viewSize.height <= 0) {
            null
        } else {
            dragToShape(
                startU = a.x / viewSize.width,
                startV = a.y / viewSize.height,
                endU = b.x / viewSize.width,
                endV = b.y / viewSize.height,
                type = type,
            )
        }
    }
    Column(modifier = modifier) {
        Text(text = imageEditorHint(), style = texts.caption, color = colors.secondaryText)
        Box(
            Modifier
                .fillMaxWidth()
                .onSizeChanged { viewSize = it }
                .pointerInput(type, viewSize) {
                    detectDragGestures(
                        onDragStart = { off -> dragStart = off; dragCurrent = off },
                        onDrag = { change, _ -> dragCurrent = change.position; change.consume() },
                        onDragEnd = {
                            val a = dragStart
                            val b = dragCurrent
                            val s = viewSize
                            if (a != null && b != null && s.width > 0 && s.height > 0) {
                                dragToShape(
                                    startU = a.x / s.width,
                                    startV = a.y / s.height,
                                    endU = b.x / s.width,
                                    endV = b.y / s.height,
                                    type = type,
                                )?.let(onAdd)
                            }
                            dragStart = null
                            dragCurrent = null
                        },
                        onDragCancel = {
                            dragStart = null
                            dragCurrent = null
                        },
                    )
                },
        ) {
            // 已定型的块：复用渲染层，`onRevealAll` 传 null（编辑时不该有"点按全揭"那个手势）
            OcclusionImage(model = photo, shapes = shapes)
            if (liveShape != null) {
                Canvas(Modifier.matchParentSize()) {
                    val r = shapePixelRect(liveShape, size.width, size.height)
                    drawRect(color = colors.warning.copy(alpha = 0.35f), topLeft = r.topLeft, size = r.size)
                    drawRect(
                        color = colors.warningInk,
                        topLeft = r.topLeft,
                        size = r.size,
                        style = Stroke(width = 2.dp.toPx()),
                    )
                }
            }
        }
        Text(
            text = if (shapes.isEmpty()) "还没有遮挡块" else "已加 ${shapes.size} 处遮挡",
            style = texts.caption,
            color = if (shapes.isEmpty()) colors.secondaryText else colors.successInk,
        )
        Row(horizontalArrangement = Arrangement.spacedBy(AppTheme.space.sm)) {
            AppButton(text = "矩形", secondary = type == EditorShape.RECT, onClick = { onTypeChange(EditorShape.RECT) }, modifier = Modifier.weight(1f))
            AppButton(text = "椭圆", secondary = type == EditorShape.ELLIPSE, onClick = { onTypeChange(EditorShape.ELLIPSE) }, modifier = Modifier.weight(1f))
        }
        Row(horizontalArrangement = Arrangement.spacedBy(AppTheme.space.sm)) {
            AppButton(text = "撤销上一块", secondary = true, enabled = shapes.isNotEmpty(), onClick = onUndo, modifier = Modifier.weight(1f))
            if (shapes.size > 1) {
                AppButton(text = "清空", secondary = true, tone = AppButtonTone.Warning, onClick = onClear, modifier = Modifier.weight(1f))
            }
        }
    }
}
```
