# StudyKit v3.3：阶段 × 题型 × 判分方式

> 状态：2026-10-24 设计定稿（施工中）。版本 `3.3.0 / 24`；Room v9 → v10 → v11。
> 本文先定“考什么、怎么判”，再谈 UI。**不内置任何受版权保护的题库**，只做元数据、导入与筛选。

## 0. 一句话

题库从“只有单选”扩成 **5 个考试阶段 × 7 种题型 × 3 种判分模式**；用户可以在学科入口按
“阶段 + 题型”两行筛选，客观题自动判，半客观题先自动比对、失败再自评，主观题只自评并明确标注。

## 1. 考试阶段（ExamStage）

`questions.exam_stage TEXT NOT NULL DEFAULT ''`，`''` = 未标注（与 `concept_tag` 的 v7 先例一致）。
不建独立表：阶段与题一对一、无属性、无生命周期；建表只会让取题/备份/导入/错题溯源多一次 join。
**阶段不是学科的子类**：数学可以出现在初中/高中/大学/考研；行测、申论是学科名，不得反推阶段，
也不得把“考公”做成学科。阶段不做父子层级（考研与大学并列）。

| 枚举 | 存储值 | 显示 | 典型学科 |
| --- | --- | --- | --- |
| JUNIOR | `junior` | 初中 | 语文/数学/英语/物理/化学/道法/历史/地理/生物 |
| SENIOR | `senior` | 高中 | 语文/数学/英语/物理/化学/生物/政治/历史/地理 |
| COLLEGE | `college` | 大学 | 高数/线代/概率/专业课/英语四六级 |
| POSTGRAD | `postgrad` | 考研 | 政治/英语一/英语二/数学一/数学二/数学三/专业课 |
| CIVIL_SERVICE | `civil` | 考公 | 行测（常识/言语/数量/判断/资料分析）、申论 |
| UNSPECIFIED | `''` | 未标注 | 旧题/用户暂不分类 |

别名（导入）：中考→JUNIOR，高考→SENIOR，本科→COLLEGE，研究生→POSTGRAD，公考/国考/省考→CIVIL_SERVICE。

## 2. 题型（QuestionType）与判分模式

沿用现有 `question_type TEXT` 列（v10 已建），只扩字符串值；不新增 `QuestionFormat` 第二真值。
`GradingMode` 由题型**纯派生**，不落库。

| 题型 | 存储值 | 判分模式 | 说明 |
| --- | --- | --- | --- |
| SINGLE | `single` | AUTO_KEYED | 单选，一个正确下标 |
| MULTIPLE | `multiple` | AUTO_KEYED | 多选，集合完全相等才算对；部分分只展示 |
| TRUE_FALSE | `true_false` | AUTO_KEYED | 判断题，固定选项 正确/错误，复用单下标 |
| FILL | `fill` | AUTO_NORMALIZED | 填空，多个可接受答案，规范化比对；失败自评 |
| CALCULATION | `calculation` | AUTO_NORMALIZED | 计算题，数值/表达式答案规范化比对；失败自评 |
| SHORT_ANSWER | `short_answer` | SELF_RUBRIC | 简答/名词解释，参考答案 + 评分点，自评 |
| ESSAY | `essay` | SELF_RUBRIC | 论述/材料分析/申论/写作，参考答案 + 评分点，自评 |

- **绝不假装自动判主观题**：SHORT_ANSWER/ESSAY 的 `GradeResult` 永远 `needsSelfJudge=true`，
  `correct` 默认 false，等用户自评；不自评就进不了下一题。
- **判断/单选/多选**：`AUTO_KEYED`，只认一个/一组下标。
- **填空/计算**：`AUTO_NORMALIZED`，规范化后与多个可接受答案逐字比较；不命中时给参考答案，
  用户可点“算我写对/算我写错”。计算题的表达式不做符号等价（不引入 CAS），只做字符串规范化 +
  多答案；这是明确边界。
- **多选部分分不进 FSRS**：`correct` 仍是集合相等；`partialCorrect/partialTotal` 只用于反馈。

### 2.1 阶段 × 题型矩阵（官方大纲核对版）

读法：**核**=主流试卷稳定出现且占比高；**常**=多数试卷/学科出现；**少**=个别省份/学科/专业；
**无**=该阶段主流考试不出现（不含校内自编题）。**“资料分析/阅读/完形/听力”是内容模块，不是题型**；
行测里的数量关系/资料分析在作答形式上仍是单选，不得塞进 CALCULATION。

| 题型 | 初中 | 高中 | 大学 | 考研 | 考公 |
| --- | --- | --- | --- | --- | --- |
| 单选 | 核 | 核 | 常 | 核 | 核 |
| 多选 | 少 | 常 | 常 | 核 | 无（公安专业科目除外） |
| 填空 | 核 | 核 | 常 | 常 | 无 |
| 判断 | 少 | 无 | 常 | 少 | 无 |
| 简答/名词解释 | 核 | 核 | 核 | 核 | 无 |
| 计算 | 核 | 核 | 核 | 核 | 无 |
| 论述 | 常 | 核 | 核 | 核 | 核 |
| 材料分析/案例 | 核 | 核 | 核 | 核 | 核（申论小题） |
| 写作/申论 | 核 | 核 | 常 | 核 | 核（申论大作文） |

三个必须写进产品的边界：
1. **考公公共科目没有多选/判断/填空/简答/计算**；行测是单选承载计算，申论是主观。公安专业科目另有
   单选/多选/情境，属于单独口径，不并进普通考公。
2. **大学列不是全国口径**：高校自主制定教学计划（《高等教育法》第 34 条），教高〔2019〕6 号要求
   笔试/口试/非标准答案等多种形式；表中是校内常见，不确定性最高。CET/NCRE/教资等国家统考另计。
3. **初中省际差异大**：2019 年取消中考大纲，考试方式由省级确定；2022 年提出 2024 年省级统一命题目标，
   但各地卷型仍不完全一致。题目上的阶段是**用户标注**，不是应用替考试院下结论。

### 2.2 判分契约（不是题型唯一决定）

同一个 MULTIPLE 在不同考试里规则不同：2025 新高考数学多选全对 6 分、部分对部分分、有错 0 分；
考研政治多选少选/错选均 0 分。因此：
- **本版 `correct` 统一按“全对才算”**（集合完全相等），用于练习判定与排期；
- **部分分只展示**（`partialCorrect / partialTotal`），不写 FSRS、不写 review_log；
- 在 UI 与发版说明里明确“这是本应用的保守口径，不冒充各考试的真实评分细则”；
- 考试特定的部分分策略（高考数学 vs 考研政治）留作后续 `ScoringPolicy`，本版不做。

## 3. 判分证据与官方依据

### 3.1 判分证据（摘要）

- **提取练习**：Roediger & Karpicke (2006) 的测试效应；McDermott et al. (2014, JEP: Applied) 在课堂材料上
  比较选择题与简答题：选择题即时表现更好，简答题长期保持略优；**反馈对两种格式都有增益**。
- **再认 vs 线索回忆**：Kang, McDermott & Roediger (2007) 的两个实验显示结论随反馈方向反转：
  无反馈时选择题不差甚至更好，有纠正反馈后简答最优。Lawson (2022) 的课堂实验未发现选择题与填空的
  显著差异。**不能宣称“填空一定优于选择”**；产品保留两种，让用户按阶段/科目选。
- **多选部分给分**：Frary (1989) 综述认为部分给分几乎没有测量学优势；Persson (2023) 是理论工作，
  不含信效度实证；Schneid et al. (2025) 报告部分给分改善分数与体验，但样本小、是单选题近邻加权。
  **证据不一致**。本应用因此只展示部分分，不把部分分写进 FSRS。
- **填空自动判分**：字符串精确匹配的假阴性主要来自同义、缩写、单位、语序（Burrows et al. 2015 综述）。
  规范化只能消除格式噪声；自动不命中时给参考答案 + 二次自评，并**不把自评写进校准流**。
- **主观题自评**：rubric 对学习与自我调节有中等正向作用（Panadero & Jonsson 2013），但评分信度依赖
  分析性、题目特定细则与培训（Jonsson & Svingby 2007）；自评系统性高估（León et al. 2023）。
  因此 SHORT_ANSWER/ESSAY/CASE_ANALYSIS 只做“参考答案 + 评分点 + 自评”，并明确 `evidence=self`。
- **自评与排期**：自评不是伯努利结果，直接写 review_log 会让校准器把“用户宽容”学成记忆强度。
  本版：**客观自动判写入 review_log；任何自评（填空回退/简答/论述/材料）只写 practice_records，
  不写 review_log**。这是保守但可解释的口径。

## 4. 数据模型（Room v11）

v10 已加 `question_type` / `answer_indices_json` / `answer_text_json`，**冻结不改**；
v11 只加阶段与复合索引：

```sql
ALTER TABLE questions ADD COLUMN exam_stage TEXT NOT NULL DEFAULT '';
CREATE INDEX index_questions_exam_stage_question_type_subject
  ON questions(exam_stage, question_type, subject);
```

- `Question` 加 `examStage: String = ""` 与 `stageEnum`；`QuestionType` 扩 7 值。
- `answer_text_json` 一词二义，必须按题型分派：FILL/CALCULATION 是可匹配答案；
  SHORT_ANSWER/ESSAY 是参考答案（首元素）+ `explanation` 评分要点；`acceptedAnswers()` 只对
  FILL/CALCULATION 返回可匹配列表。
- `SubjectStageFormatCount(subject, stage, type, count)` + DAO `observeSubjectStageFormatCounts()`。
- Repository 三维取数：`getBySubject(subject, stage, format, limit, offset)`；旧签名保留。

## 5. UI

- 学科入口两行 chips：
  - 阶段：全部 / 初中 / 高中 / 大学 / 考研 / 考公 /（有未标注题时）未标注
  - 题型：全部 / 单选 / 多选 / 判断 / 填空 / 计算 / 简答 / 主观
  - 两行都是筛选器，不级联；无题组合置灰；学科卡显示当前组合的题数。
- 综合练习：两条件过滤后 ≥2 个学科才出现；交错仍只作用于学科层与题面层。
- 作答：
  - SINGLE/TRUE_FALSE：点选项即提交；TRUE_FALSE 固定“正确/错误”。
  - MULTIPLE：勾选后提交；全对才算对，反馈显示“选对 x / y”。
  - FILL/CALCULATION：文本输入 + 提交；自动不命中时显示参考答案与自评按钮。
  - SHORT_ANSWER/ESSAY：不要求输入正文（用户在纸上写），直接“看参考答案/评分点 → 自评对错”；
    也可留一个可选草稿框，但不参与判分。
- 模考：只收 AUTO_KEYED 且单值可编码的 SINGLE + TRUE_FALSE；多选/填空/计算/主观不进模考
  （`mock_sessions.answers` 是单下标）。阶段筛选对模考生效。
- 错题本：正文文本化；客观题写“正确答案”，多选/填空/计算/主观写“正确答案/参考答案 + 你的作答”，
  `RedoFlow` 在第一个“正确答案：/参考答案：”行切分，重做阶段一起遮住。错题列表本轮不加阶段筛选。
- 统计：只加“题库构成（阶段 × 题型）”计数卡；不做阶段正确率（旧 practice_records 没有题型/阶段列，
  主观题正确率又是自评）。

## 6. 导入格式

前缀扩为 `[阶段·学科·题型]`，`·` 或 `/` 分隔；任一段可省，但题型必须能识别；旧 `[单选]` 与无前缀行不变。

```
[高中·数学·单选] 题干|A|B|C|D|B
[初中·英语·填空] 题干|答案1;答案2|解析
[考公·行测·判断] 题干|正确|解析
[考研·数学一·计算] 题干|答案1;答案2|解析
[考研·政治·简答] 题干|参考答案|评分要点|解析
[考公·申论·主观] 材料/题干|参考答案|评分要点|解析
```

- 判断题答案只认 正确/错误/对/错（或 T/F）；选项固定为“正确/错误”。
- SHORT_ANSWER/ESSAY：第二列参考答案、第三列评分要点、第四列解析；绝不自动判。
- 识别不了的 token 进待修正（新增 `UNKNOWN_PREFIX`），绝不退回题干。
- `ImportItem.Question` 加 `stage/format/subject`；去重键加 stage/format；导入不再一律“未分类”。
