# StudyKit v2.3 记忆排期改造设计

日期：2026-09-22　分支：`feat/v2-visual-motion`（起点 `3f8fa1f`）
参照素材：`C:\Users\Administrator\Desktop\记忆算法调研\`（墨墨背单词真机 7 张截图）

## 0. 一句话结论

现在这套"答对 +1 天 / +3 天、答错 +10 分钟"的写死阶梯，**间隔与历史答对次数无关**，
一个词背到第 20 次复习仍然只隔 3 天——这不是间隔重复，是"间隔三天"。
本方案把它换成**以半衰期为状态量的遗忘模型**（p = 2^(−Δt/h)），
用墨墨在 KDD 2022 公开的那组系数直接算每次复习后的新半衰期，
复习点定在"预测记住率掉到目标值"的那一刻，并把目标值锚在设置页已有的**考试日期**上。

## 3. 论文依据（同行评审的与厂商自述的分开标）

**A. 同行评审、可直接引用**

1. **Cepeda, Pashler, Vul, Wixted & Rohrer (2006)**. *Distributed practice in verbal recall tasks:
   A review and quantitative synthesis.* **Psychological Bulletin, 132(3), 354–380**. PMID 16719566.
   → 取的是：**最优间隔不是常数，它随"要保持多久"线性放大**。复习点应该由目标保持期反推，
   而不是拍一个"3 天"。这直接支撑第 5 节把考试日期当锚点。
2. **Smolen, Zhang & Byrne (2016)**. *The right time to learn: mechanisms and optimization of
   spaced learning.* **Nature Reviews Neuroscience, 17(2), 77–88**. PMID 26806627.
   → 取的是：**间隔-效果曲线是非单调的**（分子级存在"过短无效、过长也无效"的窗口）。
   所以必须设**上限**，不能"越久越好"地让间隔发散。
3. **Roediger & Karpicke (2006)**. *Test-enhanced learning: taking memory tests improves
   long-term retention.* **Psychological Science, 17(3), 249–255**. PMID 16507066.
   → 取的是：**提取本身就是学习手段**。所以"先回忆、后看答案"这一步不能被跳过，
   而且摘录/错题这类现在不考的地方也该给一次自测。

**B. 墨墨自己的两篇（工程上最可落地，但收益数字是厂商自述）**

4. **SSP-Mem** — *A Stochastic Shortest Path Algorithm for Optimizing Spaced Repetition Scheduling*,
   **KDD 2022**，DOI [10.1145/3534678.3539081](https://dl.acm.org/doi/10.1145/3534678.3539081)
   （[墨墨中文解析](https://memodocs.maimemo.com/docs/2022_KDD)）。
   → **本方案的模型骨架直接用它公布的解析式**（见第 5 节），因为它不需要训练、
   三个数就能算，单用户离线也能跑。
5. **DSSM** — *Optimizing Spaced Repetition Schedule by Capturing the Dynamics of Memory*,
   **IEEE TKDE**，[ieeexplore 10059206](https://ieeexplore.ieee.org/document/10059206)
   （[中文解析](https://memodocs.maimemo.com/docs/2023_TKDE)）。
   → 用 GRU 替掉部分解析式，自述 MAE/sMAPE 降 64%、复习总开销降 17%。
   **本方案不做这部分**（见第 9 节"明确不做"）：单机 App 没有千万级日志喂它。

> 诚实标注：第 5 节那组系数（3.81 / −0.534 / −0.127 / 0.970 / −0.041 / 0.377 / −0.227）
> 是从墨墨公开的中文解析里抄的，我**没有**逐字核对论文正文 PDF。
> 起初怀疑失败支的指数排布不对称（同一支里既出现 −0.041 又出现 0.377），
> 手算后确认那是**设计而非笔误**：失败支直接回归出新半衰期，因此有个 ≈1.2 天的不动点（见 5.1）。
> 实现按"参数可注入 + 单测钉住轨迹"处理，上线前用第 8 节的历史回放校准，而不是当真理。

## 4. 状态量：一个记忆单元要记什么

```
h      半衰期（天）——回忆概率掉到 50% 所需时间，本模型唯一的核心状态
d      难度（无量纲，≥1，封顶 10）
lastAt 上次复习时刻（epoch ms）
target 该单元的目标准确率（来自全局严格度 + 考试日反推）
```

`status`(NEW/LEARNING/MASTERED) **保留但降级为展示用**：由 h 派生
（h<1 天=学习中，h≥7 天=已掌握），不再参与调度判断。理由：三档状态机是现在所有毛病的根源。

## 5. 模型公式（SSP-Mem 解析式，参数可注入）

回忆概率（指数遗忘，半衰期形式）：

```
p = 2^(−Δt / h)          Δt = (now − lastAt) / 一天
```

复习后状态转移（r = 1 认识 / 0 忘记；r = 0.5 模糊按失败支处理，见第 6 节）：

```
成功：h' = h · (exp(θ1) · d^θ2 · h^θ3 · (1−p)^θ4 + 1)      θ1=3.81 θ2=−0.534 θ3=−0.127 θ4=0.970
失败：h' = exp(φ1) · d^φ2 · h^φ3 · (1−p)^φ4                φ1=−0.041 φ2=−0.041 φ3=0.377 φ4=−0.227
难度：d' = d（成功） / min(d + θd, 10)（失败）              θd 默认 0.1
```

下次复习时刻（**这就是全部调度逻辑**）：

```
Δt_next = h' · log2(1 / target)      →  nextAt = now + Δt_next·一天
```

`target = 0.9` 时 Δt_next ≈ 0.152·h'。也就是"35 天后复习"对应 h' ≈ 230 天。

**冷启动**：新词 `h0 = 0.5 天`、`d0 = 1.0` → 首复习 ≈ 1.8 小时后（当天内），
第二次若仍认识，h 按公式跳到 ≈ 5 天量级。这条轨迹必须用单测钉住（第 8 节）。

**上限（Smolen 的非单调窗口 + 工程兜底）**：`Δt_next = min(Δt_next, capDays)`，
`capDays` 由第 6 节的考试日锚点给出，且硬上限 365 天。

## 6. 三档评分与目标值

| 按钮 | r | 语义 | 处理 |
|---|---|---|---|
| 认识 | 1.0 | 秒答 | 成功支 |
| 模糊 | 0.5 | 想起来了但犹豫 | **h 走成功支、d 走失败支**（间隔照样拉长，但拉长幅度打折）——比"当成忘记"更贴合用户直觉，也避免一次犹豫把词打回 10 分钟 |
| 忘记 | 0.0 | 没想起来 | 失败支，且 `nextAt = now + max(10 分钟, 0.05·h'·一天)` |

**目标记住率 target 由考试日期反推**（把 Cepeda 的"间隔随保持期放大"变成可操作规则）：

```
R = max(7, 距考试天数)          // 要保持多久
target = clamp(0.95 − 0.05·⌊R/60⌋, 0.75, 0.95)   // 越远的目标越宽松
capDays = clamp(R · 0.2, 3, 365)                  // 最优间隔约为保持期的 1/5
```

方向是**越远越松**（不是越远越严）：下周就考，忘一次的成本极高，不许它掉（R≤60 → 0.95）；
半年后才用得上，让它掉到 0.75 再提取，那一次复习的加固效果最强、总耗时最省。
R=60→0.90、120→0.85、180→0.80、≥240→0.75。

设置页给一个「复习严格度」三档滑块（宽松 0.80 / 标准 0.88 / 严格 0.95）覆盖默认值，
**默认跟随考试日期**。考试日期为空时 target 取 0.90。

### 5.1 手算复核（已用 `记忆算法调研/verify_model_math.py` 逐条验过）

| 检查 | 结果 |
|---|---|
| 新词首复习 | h=0.5、target=0.9 → **1.82 小时后**（当天内再碰一次） |
| 第 1 次"认识"后 | h = 0.5 → **3.1416 天** |
| 连续 6 次"认识"的间隔 | 0.478 → 2.475 → 10.877 → 41.471 → 139.883 → 365（撞硬上限）天，**严格递增** |
| 墨墨真机同一位置的按钮 | 第 5 次复习时我们给 **41.5 天后**，墨墨给 **35 天后** —— 同一量级，说明这套公开系数能复现它的产品行为 |
| "忘记"的失败支 | h=10 → 2.676 天（砍 7 倍）；h=0.5 → 1.247 天（**反而升**） |

最后一行不是 bug：失败支是**直接回归出一个新的 h**（`h' = exp(φ1)·d^φ2·h^φ3·(1−p)^φ4`），
不是"把 h 乘一个小于 1 的系数"，所以它有一个 ≈**1.205 天**的不动点 —— 任何词被忘记后
都会向 1.2 天收敛，已经比这更短的记忆不会因为一次忘记被压到零。
这条已写成测试 `forgetting pulls a long memory down and never explodes a short one`，
**防止以后有人"顺手修正"成单调下降**。


## 7. 数据迁移（Room v4 → v5）

`words` 加列：`half_life_days REAL NOT NULL DEFAULT 0.5`、`difficulty REAL NOT NULL DEFAULT 1.0`、
`last_review_at INTEGER`、`total_reviews INTEGER NOT NULL DEFAULT 0`、`lapses INTEGER NOT NULL DEFAULT 0`。

`word_reviews` 加列（**这一张表是能不能校准的全部本钱**）：
`gap_days REAL`（复习时距上次多久 = 模型的自变量）、`p_at_review REAL`（当时预测记住率）、
`grade INTEGER`（0/1/2 三档，替代 `correct` 但保留 `correct` 兼容旧数据）、
`h_before REAL`、`h_after REAL`、`reaction_ms INTEGER`。

迁移用 `MIGRATION_4_5` 手写 `ALTER TABLE ... ADD COLUMN`（全部带 DEFAULT，旧行不炸），
`mistakes` 同步加 `half_life_days/difficulty/last_review_at` 三列，并新建 `mistake_reviews` 历史表。

**为什么现在就能校准**：`word_reviews` 里已有 `reviewed_at` 序列，
相邻时间戳差 = gap_days，`correct` = r。老数据虽然缺 `p_at_review`，
但可以用"从第一条开始正向推演 h"的方式补齐——所以第 8 节的回放在**存量数据上就能跑**。

## 8. 校准与验证

1. **历史回放（存量数据，上线前必做）**：把用户已有的 `word_reviews` 按时间顺序喂进模型，
   每次复习前记录预测 `p`，事后对比实际 `r`，算 **Brier 分数**与分桶可靠性表
   （预测 0.9 的那批实际对了多少）。Brier ≤ 0.15 才算"模型比抛硬币强"，
   否则调 `h0/θd/target` 而不是改代码逻辑。
2. **单测黄金轨迹**（JVM，无需真机；`MemoryModelTest`，期望值全部手算并可从公式复现）：
   - 新词连续 6 次"认识" → 间隔严格单调递增，序列 ≈ 0.48 / 2.5 / 10.9 / 41.5 / 140 天，且 ≤ capDays；
   - 第 5 次复习给出的间隔落在 20~70 天，与墨墨真机按钮上的"35 天后"同量级；
   - "忘记"：h=10 必须砍到 5 以下；h=0.5 允许升到不动点附近但必须 <2 天（见 5.1，**故意钉住这个反直觉行为**）；
   - `p(Δt=h) = 0.5`、`p(Δt=h/2) = 0.7071`、`p` 对 Δt 单调递减、Δt=0 时 p=1；
   - 三档偏序恒成立：h(认识) ≥ h(模糊) > h(忘记)，且模糊的难度涨幅与忘记同步；
   - h/d/间隔在 d=10 封顶、gap=0、连续 500 次混合评分、以及 NaN/−Inf 脏状态输入下
     **不出现 NaN/Inf/负数，也不会排出过去的时刻**；
   - target 随保持期**变松**（0.95→0.75）、capDays 随保持期**变长**（夹在 3~365）。
3. **真机走查**：评分按钮上印的间隔与实际 `next_review_at` 一致；
   统计页未来 7 天柱状与 SQL 手算一致；把系统时间调后 30 天看队列是否按预测量出现。

## 9. 明确不做

- **不上 GRU / 不训模型**（DSSM 那部分）。单机没有千万级日志，硬上只会过拟合自己的几十条记录。
- **不做服务端**。回放校准全部在本地跑。
- **不动摘录/书的"读书笔记"**（`BookReview.rating` 是 1–5 星评价，与间隔重复无关，别硬并进来）。
- **一次不改题目模块**：先词 + 错题两条线跑通并校准，题目下一版再接。
- **不引入 FSRS/HLRS 作为并行方案**：它们同样需要在线拟合，且与墨墨公式二选一时
  先选有公开解析式、能单测钉住的那个。

## 10. 风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 参数是从中文解析抄的，未逐字核对论文 | 失败支指数排布可疑（见第 3 节标注） | 参数集中成 `MemoryParams` 注入；回放校准不通过就调参，不改结构 |
