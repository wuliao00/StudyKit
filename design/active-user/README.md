# StudyKit 主动用户改版视觉稿

按 stageshow skill 的规范制作：一个界面只说一件事，真实文案只落在焦点上，其余用留白与层级承担；手机框、状态栏、底部导航都是手绘，不是截图贴图。

## 文件

- home.png — 首页 1/3：一张「今天从哪开始」卡，签到已完成、复习是当前焦点、小测在下一格。
- done.png — 3/3 完成态：奖励来自刚才的动作（3/3、全对、连续天数），并给一个更轻的继续动作。
- quiz.png — 小测 2/3：一屏一题，答对后同时给例句；错误选项保留划痕，撤销入口在底部。

## 设计约束（来自论文）

1. 用户是来完成任务的，不是来学系统的：不做强制教程，首屏直接给可完成的小动作。
2. Production Paradox：把「学系统」藏进「完成今天的事」；一卡一动作，即时结果。
3. 风险可逆：每个写操作都有撤销/返回，做错不惩罚。
4. 渐进披露：首屏 3 个主行动，其余收进「更多」。
5. Assimilation Paradox：用熟悉隐喻（签到日历/单词卡/三题一页），但不放点进去没功能的假入口。
6. 系统模型可见：本地优先、无账号、为什么有复习，用人话写在卡上。

## 复现

直接用 Edge/Chrome 打开 home.html、done.html、quiz.html；stage.css 是全部样式。没有外部依赖、没有图片资源，字体使用系统中文宋体/黑体。

## 落地

- HarmonyOS：按本稿实现真实 60 词词库、Leitner 排期、小测、今日 0/3、练习/错题/报告。
- Android：首页 hero 上方加同一张 3 步引导卡（接现有签到/单词/题库动作），并做渐进披露折叠。
