# StudyKit v3.13.0

> 版本号 3.13.0 / 35。Room 仍 v14（无 schema 变更）。
> 本版修规则切题的脏数据：节标题和分值行不再被续进题干/选项。

## 这一版做了什么

### 节标题 / 分值行识别

- 节标题：一、/ 二、…、第 X 部分 / 大题 / 卷、选择题（每题 3 分）、注意事项、考试说明、
  考生须知 -> 结束上一题并整行跳过；
- 分值行：本题 5 分、（共 10 分）、满分 12 分、分值：12 分 -> 跳过，只计入该题置信度；
- 普通句子如「下列说法正确的是」不会被当成节标题；
- 新增 3 条 QuestionLayoutParserTest 用例钉住以上规则。
