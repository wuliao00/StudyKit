# StudyKit v3.2.0：夜间「夜读」与交互主次

> **状态：v3.2.0 发版说明（2026-10-21）。** 写作口径沿用本仓既有规矩：每个数字与结论都标证据类型。
> - **机检** = JVM / Robolectric 自动化，GitHub Actions `CI` 在 `caf88fa` 与 tag 提交 `554dc81` 上均全绿；
> - **组件渲染** = Compose 预览渲染，不是真机实拍；
> - **真机** = 2026-10-21 在 vivo V2156A / Android 11 上完成的装机与首页/题库冒烟（见「四、装机与冒烟」）；
> - 没验的事一律进「五、诚实边界」，不写成已成立。

这一版 = **v3.1 的端侧语义交错与模型包管理地基** + **v3.2 的夜间/材质重做与交互主次**。
只动观感、材质与交互层级；**没有改页面文案、数据、调度，也没有改 v3.1 的语义交错逻辑**。
学习数据仍然只在本机：Room 仍是 `version = 9`，从 3.0.0 覆盖升级不迁移、不丢存量。

## 一、夜间「夜读」与材质重做（v3.2-A）

- 深色从暖褐改成冷石墨：页面底 `#0C0E11`、卡面 `#15181D`、主文字 `#F4F5F7`、次文字 `#9CA3AC`。
  逐对实测（vs 卡面 / 页面底）：主文字 16.31 / 17.72，次文字 6.99 / 7.59，accentInk 12.18 / 13.24，
  全部 AA 以上；品牌色 `#3ECBB6` 在卡面上 8.83:1。
- **毛玻璃重做**：删掉整条「流动亮带」（底栏与打卡弹层各养一枚 `Animatable`，只为一次扫光）。
  现在是中性底（SOFT 78% / STRONG 92%）+ 顶部 10% 白高光 + 一圈随主题换角色的细切割边；
  底栏再加一层 10dp 轻投影，白天靠它与纸面分开，夜间几乎不可见。
- Hero 卡不再是半透明绿玻璃，改成「被灯照到的实底卡」：品牌色 10% 只留在顶部渐变，
  左侧读数环后一团 20%（夜间）/ 10%（浅色）的径向光晕；环底从 divider 改成 14% 主文字色
  （旧版夜间那圈几乎看不见，像断掉的弧）。
- 首页三块统计卡收成一条数据带（同一卡面 + 两枚细分割线，标签在上、数值在下），
  1165 这类长值不再把标签挤成两行。
- 字阶：大标题 32sp（-0.8 字距）、正文 16sp、辅助 14sp；数字统一 `tnum` 等宽，hero 46sp、统计 30sp。
  浅色次要文字从 `#8A857C` 压深到 `#766F64`（卡面 4.89:1 / 页面底 4.68:1）。
- 所有页面共用一层「光从上方来」的底纹（卡面色 72% → 页面底色）；hero 进入首页原有的
  `StaggeredIn` 序列（0），三张入口卡顺延 1/2/3 级；入口卡按下时 0.98 回弹。
- 底栏选中态从一整枚高饱和青胶囊收成 10% 柔底 + `accentInk` 图标/文字；
  实底按钮夜间从 `accentInk` 改成 `accent`（`#3ECBB6` 上的暖墨字 9.51:1），浅色不变。

## 二、交互页的主次（v3.2-B）

- **题库练习**：顶部加 3dp 进度条；作答后的「下一题」钉在底部操作条，不再被长解析滚出屏幕；
  「给点提示」从整宽描边按钮降为右下角文字动作；结果页主行动改成「再来一轮」，「返回」降为次级。
- **学科选择**：每个学科加圆形首字标识 + 右侧箭头，扫视先认字；综合练习标题旁加「推荐」药丸，
  只留一个高亮入口。
- **单词库**：「开始学习」收进一张今日重点卡（大数字 + 状态句 + 实心行动），
  「截图取词」降为卡内右下角文字动作；单词条目由三列挤一行改成两行 —— 词头与熟练度一行、释义一行。
- 往返路径没变：所有按钮仍走原来的回调；`QuizDrillNoteRenderTest` 只把“先滚到下一题”改成直接点
  （按钮已钉底，旧滚动假设不再成立），断言一条没减。

## 三、随本版发布的 v3.1

### 端侧语义交错

- 相似题打散从 v3.0-C 的**词面替身**（字符二元组 Dice）换成**真嵌入**：
  题干 → bge-small-zh-v1.5 **INT8 ONNX（23.9 MB）** → 512 维 → 余弦相似度 → 既有的相邻修复 / drills。
  「意思相近但用词不同」第一次有判据，不再只看字面重合。
- 模型随安装包下发在 `app/src/main/assets/models/bge-small-zh-v1.5/`：`model_int8.onnx` 23,903,394 B
  （sha256 `b9837c19…`）、`vocab.txt` 109,540 B（sha256 `45bbac6b…`）。来源 ModelScope
  `Xenova/bge-small-zh-v1.5`（BAAI 原模型的 ONNX 转换），**MIT**；出处与两个哈希写在同目录 `PROVENANCE.md`。
- 运行时复用 OCR 已在用的 ONNX Runtime Android；分词是仓内 Kotlin 实现的 BERT WordPiece；CLS 池化 +
  L2 归一化，**不联网**。
- 回退是**整轮**的：模型/资产加载失败、任一题干嵌入失败、向量维度不一致 ⇒ 回到 v3.0 的词面 Dice 与
  `LexicalInterleave.DEFAULT`，队列结果与 v3.0 逐格相同（机检两条对照钉着）。
- 只在**会话内（≤20 题）现场算并缓存**；没有 `card_embed` 表、没有全库索引、没有充电时全库刷新。
- 设置页「相似题打散」仍**默认关闭**，不打开等于没这项功能。

### 模型包管理地基

- 清单校验、下载、sha256 校验、安装/删除、600MB 预算守卫，以及设置页「模型包（可选）」分区
  （默认构建开关关闭）。
- **这里没有可用的 AI 功能**：五个可选模型包（解释 / 朗读 / 背诵验收 / 高配结构 / 去手写）
  均未上架、未接运行时。

### 拍照录题的错题本分支

- 题库「拍照录题」解析不出「题干 | 选项… | 答案」时，不再删图 + 只提示重拍，而是把照片与 OCR 文本
  经应用内单槽转进错题本录入页；空文本才保留原提示。

## 四、装机与冒烟（2026-10-21，vivo V2156A / Android 11）

- 装机前用 `run-as tar` 全量备份应用数据 **837,120 B**（sha256 `6621a929…`）；
  `adb install -r` 覆盖安装成功，包仍是 `f86c8a85…` 调试证书，版本从 3.0.0/20 升到 3.2.0/22。
- 存量核对：首页仍显示 **1165 词 / 6 已掌握 / 2 今日到期**；Room 仍 v9，无迁移。
- 浅色与夜间首页各拍一张：冷石墨底、中性烟熏玻璃、底栏切割边与 10dp 轻投影在 LCD 上可见。
- 题库：作答后「下一题」钉在底部操作条，长解析滚到末尾仍可见。
- **当场修掉一个真机缺陷**：系统字体 1.15 倍、1080px 宽时，信心条把「非常确定」压成四行竖排；
  `ConfidenceRow` 改成 `FlowRow` 换行，320dp 渲染测试钉住「换行而不是压扁」；修复后重装复拍，
  第三档换到第二行、完整可读。

## 五、诚实边界

- **真机只覆盖首页与题库冒烟**：夜间/材质、底栏投影、题库钉底操作条已看；语义交错的设备延迟/相邻率、
  更窄的屏幕（<360dp）与超长解析、拍照书页 → 转错题本 → 保存的完整跳转仍未验。
- **没有 OLED 真机**：验收机是 LCD，OLED 暗部、玻璃透明度与投影的最终观感仍要另一台设备确认。
- **3.1 语义交错没有真机读数**：bge-small-zh INT8 在 arm64 上的加载时间、单题前向、20~30 题的组轮延迟、
  冷启动与内存峰值，一个都没测；阈值未经 200+200 人工标注对校准，不承诺「相似题一定不相邻」。
- **拍照书页 → 转错题本 → 保存**的完整真机跳转未验；本轮只有 JVM 测试钉住这条分支。
- 玻璃仍是手绘（不用系统模糊）：验收机之一是 Android 11，`RenderEffect` 不可用；
  这次只是把「绿蒙层 + 流动高光」换成中性烟熏玻璃，不是真背景模糊。
- 这是**本地 debug 包**，不是应用商店包；安装占用与下载体积不是一回事。
