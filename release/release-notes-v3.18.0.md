# StudyKit v3.18.0

> 版本号 3.18.0 / 40。Room 仍 v15（无 schema 变更）。
> 这一版把每日签到从 14 天小窗升级为整月日历，并补上本周进度与连续里程碑提示。

## 签到增强

- **整月日历**：周一开始、月初补空、固定 6 行高度；左右箭头翻历史月份，不能翻未来；
  今天描边，已签到 soft 底 + 小圆点；累计/最长连续仍显示在标题下。
- **本周进度**：首页签到卡的 7 个圆点改成本周一到周日，右侧显示「本周 X/7」，未来日期不涂色。
- **里程碑**：连续 3/7/14/30/66 天当天签到成功后，首页顶部弹金色提示「连续签到 N 天，保持住！」，
  2.6 秒自动收起，和彩带同时出现。
- **首帧占位**：冷启动时本周 7 个圆点直接按空数据渲染，不再先空白再跳出。

## 单测

新增 3 条 SignInStatsTest：本周口径（周一开头、未来不涂色、只数到今天）、
整月网格（月初补空、固定 42 格、today 标记）、里程碑精确命中。
