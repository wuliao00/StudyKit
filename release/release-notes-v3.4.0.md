## 新增：学习设计（第五个 Tab「设计」）

8 种模板，每种都有结构化字段、方法论依据和实时 Markdown 预览：

| 模板 | 解决什么 | 依据 |
|---|---|---|
| 费曼学习 | 讲给外行听，暴露“以为懂了”的缺口 | 费曼技巧 + 自测效应 |
| 习题带练 | 从例题到变式，把解题思路写出来 | 波利亚《怎样解题》+ 例子学习/变式 |
| 学会学习 | 用一周证据调整方法，而不是更用力 | Dunlosky et al. 2013 |
| 互动工作坊 | 用活动让参与者自己得出答案 | Kolb 体验式学习循环 |
| 系列课规划 | 多课时排成一条递进线 | 课程地图 + 目标—活动—评价对齐 |
| 逆向教学设计 | 先定目标与证据，再排活动 | Wiggins & McTighe |
| 核心素养备课 | 把素养目标翻译成可观察的任务 | 中国学生发展核心素养 + 课标 |
| 螺旋式课程设计 | 同一概念多轮回来，每次更深 | Bruner《教育过程》 |

- 方案保存在本机 Room，可继续编辑、复制全文、用系统分享发给别人。
- 编辑草稿会随转屏/进程回收恢复，不会因为切出去看一眼资料就白填。
- **不是 AI 生成**：生成器只拼装你填的内容；必填项缺失时写“（待补充）”，不替你编。

## 新增：题库文件导入

批量录入题目页的「选文件」现在支持：

- `.txt` / `.md` / `.csv`：UTF-8、UTF-16、GBK/GB18030 自动识别，中文旧编码不乱码。
- `.docx`：读取 Word 正文，还原段落与换行；公式、图片、批注、页眉页脚不导入。
- `.pdf`：先取文字层；扫描版没有文字层时，用端侧 OCR 识别**前 20 页**，会提示“建议核对”。
- `.doc` / `.wps`：先看文件头。改过后缀、实际是 docx/zip 的直接读；真旧版二进制或 RTF 才提示另存。
  单文件上限 40MB。

导入格式仍是“一行一题、竖线分列”：

```
[阶段·学科·题型] 题干 | 选项A | 选项B | … | 答案 | 解析
```

## 新增：37 道原创示例题

批量录入题目页点「示例题库」，可以一次看到 6 个阶段（初中/高中/大学/考研/考公）与
8 种题型（单选/多选/判断/填空/计算/简答/主观/材料）的完整写法，再照着改成自己的题。

示例题为原创，不包含高考/考研/国考真题或教材原题。来源与授权边界见
[`docs/question-bank-sources.md`](../docs/question-bank-sources.md)。
