# StudyKit v3.20.0

> 版本号 3.20.0 / 42。Room v16（daily_sign_ins 加 makeup 列）。
> 这一版补上签到里的“补签”：错过一两天不用从零开始。

## 补签

- 整月日历里最近 3 天（不含今天/未来）的未签格子可点；
- 点击弹确认框「补签 11 月 5 日？补签会计入连续签到和本月统计，并在日历里标出」；
- 确认后写一条 makeup=true 的签到：日历格子 goldSoft 底 + 金色圆点，读屏报「已补签」；
- 签到卡本周圆点把补签标成金色，和正常签到区分；
- 补签计入连续/累计/本月签到率，但不改变今天是否已签；重复补签自动忽略。

## 数据

- Room v16：daily_sign_ins 加 makeup INTEGER NOT NULL DEFAULT 0；
- MIGRATION_15_16 + Migration15To16Test：旧签到全部按正常签到，不丢行。
