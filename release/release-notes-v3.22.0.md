# StudyKit v3.22.0 — 第一眼就有用

## 一句话

**拍一下错题，自动安排复习，完全离线、无广告、开源。**

> StudyKit · 错题本·背单词·打卡

## 这次改了什么

- 首页「今天从哪开始」：签到、复习、小测三步，安装后 60 秒内可完成第一次复习。
- 首次启动预置 3 道示例错题（数学公式 / 英语 / 形近词），不用先录入就能体验“错题 → 复习队列”。
- 词书商店一键装 CET-4 / CET-6 / 考研词书，离线可用；已有词库继续保留。
- 学习报告、连续签到、记忆曲线可生成带 StudyKit 水印的分享海报。
- 错题本支持一键导出可打印 PDF。
- 设置里的 FSRS 校准从一句“还差 N 次”变成可见进度条：
  **再复习 X 次，解锁你的个人记忆曲线。**
- 底部「设计」改名「计划」，应用副标题统一为“错题本·背单词·打卡”。
- 搜索关键词：错题本、间隔重复、FSRS、离线、背单词、打卡。

## 签名迁移（重要）

从 v3.22.0 起 Android 改用正式 release 签名。debug 签名与 release 签名不同，**不能直接覆盖安装**。

迁移步骤：

1. 旧版「设置 → 备份」导出 zip；
2. 卸载旧版；
3. 安装 v3.22.0；
4. 「设置 → 备份」恢复 zip。

学习数据、签到、错题、词书都在备份里；备份只在本机，不上传。这也是 StudyKit 的信任卖点：**你的数据是你的，换签名也带得走。**
