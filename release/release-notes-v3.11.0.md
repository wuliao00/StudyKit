# StudyKit v3.11.0

> 版本号 3.11.0 / 33。Room 仍 v14（无 schema 变更）。
> 本版交付纠错记录导出与 120 张拍照仿真评测；弯曲书页去展平是原型，默认未启用。

## 这一版做了什么

### 1. 纠错记录导出

- 校对页「记录」弹窗新增「导出 JSON」；
- 写 cache 后通过 FileProvider + 系统分享面板交给用户选择去向，不自动上传；
- 内容：questionId、createdAt、before/after 题干与答案、OCR 置信度、来源页路径；不含图片。

### 2. 120 张拍照仿真集

- v3.9 的五类 100 张基础上，新增 photo_curved 类 20 张：纸张上下边界按正弦弯曲 + 透视 + 阴影；
- 真模型（桌面 ORT）跑 CER，结果：120 张（含 photo_curved 20）默认构建实测：平均 CER 13.33%（语料级 13.56%），P50 0%，P90 77.30%，
  CER<=0.05 100/120；平面五类全部 <=0.01，photo_curved 0.782 拉高整体。
  原型去弯曲可把整体压到 0.090、photo_curved 0.522，但仍远高于可用阈值，故本版不启用。
- 注意：仍是合成退化图，不是真实用户拍照集。

### 3. 弯曲书页去展平（原型，默认未启用）

- 新增 CurvedPageDetector：灰度/Otsu/最大亮区，逐列取纸张上下边界；宽窗中值滤 + 平滑压掉
  阴影/手指造成的边界平台，按「最大残差 / 页高」算曲率；曲率 1.2%..12% 才做纵向展开；
- CurvedPageDewarper：用 Canvas 按列把上边界拉到 0、下边界拉到 H，避免 Robolectric 下
  Bitmap.getPixels 的异常数据；
- 单测：合成弯曲边界检测、真实弯纸图横线拉直、平面页不误触；
- **为什么没启用**：几何上能把弯纸拉直，但纵向重采样后 OCR 对长题干仍不稳
  （photo_curved 平均 CER 约 0.52，远高于平面类），本版不接入识别管线，留作下一步。

## 真机验证（vivo V2156A / Android 11）

- **覆盖升级**：3.10.0/32 -> 3.11.0/33 直接覆盖（debug 签名一致），Room 仍 v14，数据仍在
  （questions 71、单词 1165）。
- **纠错导出**：注入 1 条纠错记录 + 1 条待校对题后，「记录」弹窗显示 C -> B；点「导出 JSON」弹出
  系统分享面板（1 个项目，可选微信/云盘）。验证后已清理，库恢复 71 题 / pending 0 / corrections 0。
- **OCR 主链**：OcrPipelineDeviceTest 抽查 clearPage 4.00s、perspective 4.16s，2/2 通过。
- **弯曲去展平**：几何原型通过单测，但接入后 photo_curved CER 仍 0.52（不接入 0.78），且真机弯纸页
  只读下半页，本版**不接入识别管线**；证据见 docs/evidence/v311-ocr-device.md。
