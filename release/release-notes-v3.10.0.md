# StudyKit v3.10.0

> 版本号 3.10.0 / 32。Room 仍 v14（无 schema 变更）。
> 本版聚焦真实试卷的「答案在页尾」排版与校对效率。

## 这一版做了什么

### 1. 页尾答案区回填

- 识别集中答案区：「答案：1.A 2.B 3.C」「参考答案 1-5 ABCDA」等；
- 按题号回填题干切出来但缺答案的题；答案区行不再被当成题干/选项续行；
- 仍缺答案的题才跳过并提示去编辑页补；
- 支持 A-H 字母、正确/错误/对/错/√/×；区间答案要求字母数与题号区间长度一致；
- 单测覆盖集中答案、区间答案、内联选项不被误判三种情况。

### 2. 校对页批量确认

- 有待校对题时显示「全部确认」，二次确认后一次清掉所有 needs_review；
- 只清标记，不改题目内容。

### 3. 纠错记录查看

- 校对页右上角历史按钮，弹窗显示最近 20 条纠错：时间、before -> after 答案、改前题干；
- 本地数据库读取，不导出、不联网。

## 机检

- **覆盖升级**：3.9.0/31 -> 3.10.0/32 直接覆盖（debug 签名一致），Room 仍 v14，数据仍在
  （questions 71、单词 1165）。
- **纠错记录**：注入待校对题、把答案 B 改成 A 保存后，库内 ocr_corrections 落 1 行 before B / after A；
  校对页「记录」弹窗显示时间、B -> A 与改前题干。
- **批量确认**：再注入 1 条待校对题，点「全部确认」出现二次确认弹窗，确认后页面变 0 道；
  验证后已清理临时题目与纠错记录，库恢复 71 题 / pending 0 / corrections 0。
- 证据：docs/evidence/v310-ocr-device.md 与 3 张设备截图。

## 已知限制

- 答案区只支持「题号+字母/判断/区间」，答案与题目编号不一致的排版仍会漏；
- 答案区假设在页面尾部，若在页面中间且之后还有题目，会被整段跳过；
- 纠错记录暂无导出/清理入口；
- 其它 OCR/版面限制同 v3.9。
