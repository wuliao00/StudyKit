# StudyKit v3.21.0

> 版本号 3.21.0 / 43。Room 仍 v16（无 schema 变更）。
> 这一版把签到接进记忆看板，并给补签加上配额与撤销，避免补签变成无成本刷连续。

## 记忆看板：签到

- 顶部新增「签到」卡：连续签到 / 最长连续 / 本月签到（X/Y）三个读数；
- 下方显示「累计签到 X 天 · 本周 Y/7」与 3/7/14/30/66 五枚里程碑徽章
  （已达成金色，未达成灰色）。

## 补签配额与撤销

- 每个自然月最多补 3 次；配额用完，日历里可补格子不再可点；
- 日历标题下显示「本月补签 X/3 次」；
- 最近 3 天内的补签格子可点，确认后撤销（删除 makeup 行），连续/本月统计同步减少；
- 补签仍只允许最近 3 天，今天/未来不可补。

## 动效

- 签到卡最高里程碑徽章在变化时做一次 1.18 -> 1.0 spring 缩放，达成时更有“点亮”感；
- 沿用 reduceMotion：开启减弱动效后不做缩放。
