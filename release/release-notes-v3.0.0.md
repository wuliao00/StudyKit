# StudyKit v3.0.0：把「会忘」和「考试」摆到同一张桌上

> **状态：v3.0.0 发版说明（2026-10-20）。** 写作口径：**每个数字/结论都要有仓内或真机证据**，
> 文中逐条标注证据类型：
> - **机检** = JVM / Robolectric 自动化，在 CI（`.github/workflows/ci.yml`）里真跑；
> - **真机** = 2026-10-16/17 首轮与 2026-10-20 收尾，均在 vivo V2156A / Android 11 上取得，读数记录在 `CHANGELOG.md` 顶部「真机验收」；
> - 未验的事一律进「六、诚实边界」，不写成已成立。

## 这一版是三件事并成的一版

**v3.0-A** 负荷预告与记忆可视化、**v3.0-B** 考试模式与照片遮挡、**v3.0-C** 相似题打散（默认关闭）。
**学习数据仍然只在你自己的手机里**：不上传、不同步、没有账号（需要联网的只有「在线词库」下载与启动时
的一次更新检查，两件都可以不用）。这一版动了数据库（Room v8→v9；从公开的 v2.5.0 升上来是 v6→v9），
迁移在手机本地完成，第一次打开 3.0.0 时自动做。

覆盖安装能不能保留数据，只取决于一件事：包是不是同一把签名钥匙（见文末「关于这份包」）。

## 一、按现在这个节奏学下去，接下来两周会堆成什么样（v3.0-A）

统计页多了一条 **14 天负荷带**：拿你现在的稳定度，把已排期的卡按遗忘曲线反解到未来每一天，
画成一条 `mean ± sd` 的带子。

要读懂它的一句话：**这条带子回答的是「照现在这个练法会堆成什么样」，不是「已经排好的日程表」。**
它故意不读落库的到期时刻——那一列只反映上一次评分排出的结果，你今天多评一轮，后面十几天会整体重排；
直接读它等于把「今天没练」这件事看不见。代价是：刚改过严格度或换过内核的那一刻，带子与今日队列可以不等
（这是设计口径，不是 bug）。（**机检**：`DueForecastTest`、`DueForecastAccuracyTest` 三道精度门；
**真机**：2026-10-16 逐屏拍过，截图 `docs/screenshots/v30a-记忆看板-01负荷带.png`。）

同屏还加了四块：

- **稳定性全景**：按 log2 分箱看你的记忆稳定度分布（**机检**：`StabilityBinsTest`）；
- **52×7 复习热力图**：按非零日分位数分级（**机检**：`ReviewHeatmapLogicTest`）；
- **单卡 R 曲线**：挂到背词页与错题详情，曲线上的「到期」标记与调度器真正会给的间隔**是同一个反解式**，
  逐值机检（`CardRecallCurveTest`）；轴、点、话统一以「今天」为原点；
- **提醒决策三档**：跌破线 > 堆积 > 到期；零到期日不再一刀切静音（堆积与跌破放行），
  提醒相位对齐到你历史上复习最多的整点，但**没有**申请精确闹钟。
  **注意**：提醒数的是「按稳定度反解出来的那批卡」，而 App 的今日列表读的是两条 SQL——
  两个数可以不等，所以到期档标题写的是「N 项按现在的状态该复习了」，没有说「今天到期」。

## 二、考试模式：把「临时抱佛脚」变成有节奏的收紧（v3.0-B）

**考试清单**：设置里可以建多场考试，每场选「管哪几科 / 考前几天开始收紧 / 收到多狠（冲刺保留率）」。
旧的单日期框被它取代；只填过旧单日期的设备，升级后会自动把那一场合成为「全学科 / 30 天窗 / 0.95」的一场
（**这是一次没有主动要过它的行为变化**，写在这里提醒你）。

**目标保留率 ramp**：进入某场考试的窗口后，目标保留率往那场的冲刺值抬，
`R(t) = R_base + (R_sprint − R_base) · clamp((D0 − t)/D0, 0, 1)`，**封顶 0.97**——
再往 1 贴，反解出的间隔会坍缩到 0 附近、复习量随之爆炸，这是那道护栏。
只抬不压：固定档（RELAXED/STANDARD）进了窗也会被抬；STRICT 本就是 0.95。
四个边界由 `ExamPolicyTest` 钉字面量：窗起点 = base、考试当天 = sprint、窗外一天 = base、**非关联学科恒 base**。
考试当天不再是「等同没填考试」：当天按最紧一档算。
**真机读数**（2026-10-16，受控探针）：两条等值卡（`S=30.0 / D=5.0 / state=3 / rc=5 / 同时到期`）
各用同一个界面动作评一次，**数学 +3.60 天、英语 +6.80 天，比值 0.53**；评后两条的 S / D / state / rc
**仍逐位相同**，唯一分岔就是到期日——差异只能来自所属考试。

**套卷（限时模拟）**：
- **按「返回」不再作废整卷**：返回 = 暂停并保留，下次进来续上（暂停期间不扣时，剩余整段补回）；
  另给一颗独立的「丢弃本卷」才真的删。
- **杀进程还能续卷**：卷子、逐题作答、光标、截止时刻都落在新表 `mock_sessions` 里
  （**真机**：`am force-stop` 后行还在、界面标「已暂停」、计时停住）。
- **到点自动交卷**（**真机**：结果页「时间到，已自动交卷」、分母 = 判过题数 3 而非总数 6、
  未答进 `toGrade`，`result = {"correct":2,"total":6,"graded":3,"toGrade":[19,20,21],"auto":1}`）。
- **分数分母改成「判过的题」**：旧版把没做完报成不会（例：20 题只判了 1 题，旧显示 5%，
  新显示 100% 并写明「判了 1 题 · 未答 19 题」）。未判的题单独成栏「待批改 N 题」，不假装判过。
- **套卷答过的题从此写进 `review_log`**：v2.9 的端侧校准器第一次能看见模考的对错与间隔。

**拍照错题的照片遮挡（以及一个从 v2.5 起就存在的洞）**：
- 照片里印着答案，就把答案那几块盖住：建卡当场能拖拽画矩形 / 椭圆，**已经存下的照片在详情页也能补画 / 改罩 / 撤罩**；
  形状存在 `mistakes.extra`，`mistakes.kind = 1` 才承认。
- 重做阶段照片归同一道门管：**没画遮挡的整张扣到对照阶段**（页面位置留一张占位卡，不让人以为图丢了）；
  画了遮挡的可以照看；**灯箱预览（点按放大那张）读同一个判定**。
- 这条修的是**自 v2.5 起就在的印刷答案泄露**：以前文字答案遮住了，照片整张摊着，
  「先自己重做再对答案」对拍照收录的错题一步都没成立。
  ⚠️ **射程只到详情页与灯箱**：错题本**列表行右侧那张缩略图没有读这道门，洞还开着**（见「诚实边界」）。

**其他两处**：考前涌量预警（确认冲刺保留率真把这一科抬高了，再按抬上去的保留率重跑负荷带，
峰值是中位的 2 倍以上才报警并说清是哪一科——这个倍数是**同一份冲刺排期自己**的形状，不是「比不冲刺多 N 倍」）；
首页倒计时那行带考试名与冲刺保留率（没抬过就不追加）；成绩页答错至少一道时多一颗「去拍这几道」，
点了带着答错的学科跳错题录入页并预选学科。

## 三、相似题打散：默认关闭（v3.0-C）

设置页新增「相似题打散」（在学科打散那行下面），**默认关闭——不打开等于没这项功能**。

打开后，题库练习与综合练习会在既有的「按学科打散」之上再加一层**题面层**交错：
题面文字上就很像的两题尽量不相邻；同一学科、同考点的对子尽量隔 **3~5 题**再遇；
成对出现时，靠后的那张题上会挂一行「这两张卡容易混，隔开放是故意的」。

判据是**题干文字（去标点后的字符二元组 Dice）+ 考点标签**，**不是语义模型**：
「意思相近但用词不同」的题看不见。不联网、不装额外东西；关掉这一层就只按学科打散，
而且**开关关着（默认）时输出与旧行为逐元素相同**（机检 `QuestionQueuePlannerTest` / `StudyQueueWiringTest` 的相等断言）。
真机读数：那句会话内提示**真的上了屏**——开开关整轮 4 次、关开关 0 次（2026-10-16，`v30c-易混提示.png`）。

## 六、这一版的诚实边界（没做 / 没验 / 验了但结论有限）

- **拍照错题的答案泄露没有全封**：详情页与灯箱已遮，**错题本列表行的缩略图仍不遮**。
  发版前要决定：补上这道门，还是在界面上明说列表页不遮。挂着这条 ≠ 已经处理。
- **照片遮挡的拖拽手势还没在真机上验过**：2026-10-16 只验到「路径通到遮挡编辑器」（相机 → 拍照 → 回编辑器）；
  画布上 `input swipe`（600/800/2200ms 三档）与 `input draganddrop` **生不出遮挡块**（逐帧像素核对无新增不透明块），
  缺的是**人手拖一次**。所以拖拽/重做遮挡这两件事目前只有代码、渲染守卫与前半段截图作证，
  真机结论要等第五节 `PASS。建卡页拖出两块遮挡（「已加 2 处遮挡」）→ 保存；库面 kind=1 / shapes=2；详情页 REDO 相位两块真盖住、提示「已遮 2 处，先回忆，点按全揭」；点按照片整层揭开；重进详情又回到 REDO 遮住。` / `PASS。无遮挡照片错题在 REDO 显示「整张照片扣住，重做后再看」且无照片；点「我重做了一遍」进 CHECK 照片露出；重进详情又回到 REDO 扣住。` 回填。
- **遮挡手势只到矩形与椭圆**：`poly` 有数据格式、也有渲染，但**没有手势**；以后加手势不用改格式、不用迁移。
- **套卷暂停没有时长上限**：暂停后隔天回来仍整段拿回，跨天暂停时「限时」可以失效；单人自用，本轮刻意不做。
- **考试 ramp 的射程有限**：① 词卡没有学科列，只被「全学科」那一场影响，只绑数学的考试不会拖紧词卡；
  ② **书摘完全接不到考试**（`ExcerptReview` 用自己固定 0.90），而负荷带把书摘算在内——
  统计页曲线会随 ramp 动、书摘实际到期不动。本轮只记账不改。
- **负荷带 ≠ 今日队列**（见「一」）：两边在刚改严格度/内核时可以不相等，这是设计口径。
- **热力图只数两路流水**（词 `word_reviews`、练习 `practice_records`）：书摘侧没有逐次复习流水，
  **只读书摘的日子不会点亮**，格子不等于「今天的全部学习量」。
- **提醒三档与今日列表是两把尺**（见「一」），两个数可以不等。
- **相似题打散**：阈值是**未校准初值**（九个参数按预期相对位置排布，本仓没有量过任何分布、没有 200+200 标注对、没有 AUC）；
  「相邻率 = 0」只在合成相似度下机检过；打开后一轮可能比设定的 10 题多一道（取数 10、拉前上限一成，整数除法）；
  「隔 3~5 题」是目标带不是保证；模考 / 错题重做 / 词卡轮不接这一层；跨学科的同考点对子永远不会被 drill。
- **A1-a 待裁定**：负荷带真机截图上看不到图注承诺的 ±1σ 阴影带，也没有轴刻度。
  轴刻度是**刻意不画**（14 个标签在窄屏会挤成一团，数字放到图下文字行）；±sd 带子**是画了的**
  （`accent.copy(alpha = 0.18f)`，按 `mean±sd` 闭合填充）。真机看不清的**成因未裁定**
  （疑为当日 sd 极小/为 0 使带子与均值线重合），**不写成「阴影没渲染」**。
- **数据库不支持降级**：v9→v8 没有回退路径（没有 `fallbackToDestructiveMigration`），降级只能靠备份恢复。
- **真实纸质照片的畸变 / 透视 / 光照**：本版无 OCR 改动，不涉及。
- **性能数字**：设备三档读数已回填（1/2/8 ms），但它**只打印、不设阈值**，单次读数没有统计意义、也不构成性能门；
  `AppLaunchSmokeTest` 在真机上挂起（>20 分钟），androidTest 这条验收目前只对基准类成立。

## 关于这份包

- **debug 签名**：这是 debug 签名包。它和 release 包唯一的区别就是签名用的那把钥匙：
  debug 那把如果丢了，重装一次就好；release 那把一旦丢了，所有装过的设备都得**卸载重装**（连带本地数据）。
  所以这里刻意不走 release。
- **签名钥匙（待回填）**：本包证书 SHA-256 = `f86c8a85…`（完整：`f86c8a854723cd50231a3173f80f96e0f32db3d0bb3d7047379c0ba75f5d61f5`）。
  **发版负责人注意**：要让「覆盖安装保留数据」对现有公开用户成立，这个证书必须与公开 v2.5.0 包一致
  （实测 v2.5.0 = `f86c8a85…`；本机默认 debug keystore 也是它）。发版前按
  `release/checklist-v3.0.0.md` 的 **G1** 决策与实测；不一致就改构建来源或改写本节措辞，别硬写。
- **覆盖安装**：装过 **v2.5.0** 的机器可以
  直接覆盖安装，学习数据、打卡记录、读书进度都会保留。从 2.4.x 或测试包升上来的机器钥匙不同，
  系统会拒绝覆盖安装——那种情况要先备份再卸载重装。）
- **校验方式**：
  - SHA-256 = `abd4fb9a80c53ada08ec2ed5f0aac4ace3d5775c2782ec1ca683ac094b9b6cb1`
  - 大小 = `95,749,436` 字节（约 91.3 MiB）
