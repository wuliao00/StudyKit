# StudyKit 3.4.1

> 只更新使用教程，不改数据与功能；覆盖安装即可。

## 教程图解

设置 → 使用教程顶部新增 4 张当前版本截图：

1. 底部「设计」入口：8 种学习/教学模板。
2. 题库练习 →「题库商店」：按阶段下载题包。
3. 下载后先预览，确认「导入」才写进题库。
4. 拍照或从相册选一页题；相册不需要存储权限。

每张截图都画了箭头；考试倒计时等个人信息已用色块遮住，并标注「隐私信息已隐藏」。
