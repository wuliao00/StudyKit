# StudyKit v3.3.0：题库阶段 × 题型 × 判分方式

> **状态：v3.3.0 开发中（2026-10-24）。** 版本 `3.3.0 / 24`；Room v9 → v10 → v11。
> 这一版只扩题库；单词/习惯/读书的数据与调度不变。
> 证据口径：**官方大纲/法规**、**同行评审论文/元分析**、**机检**、**真机**四类分开标注；
> 没验的事进「六、诚实边界」。

## 一、为什么不是“只加三个选项”

中国考试没有一张全国统一的题型表。可核对的依据是分阶段的课程标准、考试大纲和命题管理文件；
《中国高考评价体系》明确自己“不是考试大纲，也不是界定考试范围的规范性文件”。因此本版把
**作答形式（format）**、**内容模块（module）**、**评分契约（scoring）** 分开：

- **format**：怎么作答、怎么判分（单选/多选/判断/填空/计算/简答/主观/材料）；
- **module**：考什么内容（资料分析、阅读、完形、听力、实验）——本版用学科/考点文本承载，
  **不塞进题型枚举**；
- **scoring**：由题型派生，但多选的部分分规则是“评分契约”，本版明确采用保守口径（见三）。

## 二、阶段 × 题型矩阵（官方大纲核对）

读法：**核**=主流试卷稳定出现；**常**=多数试卷/学科；**少**=个别省份/学科/专业；**无**=主流考试不出现。

| 题型 | 初中 | 高中 | 大学 | 考研 | 考公 |
| --- | --- | --- | --- | --- | --- |
| 单选 | 核 | 核 | 常 | 核 | 核 |
| 多选 | 少 | 常 | 常 | 核 | 无（公安专业科目除外） |
| 填空 | 核 | 核 | 常 | 常 | 无 |
| 判断 | 少 | 无 | 常 | 少 | 无 |
| 简答/名词解释 | 核 | 核 | 核 | 核 | 无 |
| 计算 | 核 | 核 | 核 | 核 | 无 |
| 论述 | 常 | 核 | 核 | 核 | 核 |
| 材料分析/案例 | 核 | 核 | 核 | 核 | 核（申论小题） |
| 写作/申论 | 核 | 核 | 常 | 核 | 核（申论大作文） |

三条产品边界：

1. **考公公共科目没有多选/判断/填空/简答/计算**；行测是单选承载计算，申论是主观。
   公安专业科目另有单选/多选/情境，属于单独口径。
2. **大学没有全国统一题型**：高校自主制定教学计划（《高等教育法》第 34 条），教高〔2019〕6 号
   要求笔试/口试/非标准答案等多种形式；表中是校内常见，不确定性最高。
3. **初中省际差异大**：2019 年取消中考大纲，考试方式由省级确定；2022 年提出 2024 年省级统一命题目标，
   但各地卷型仍不完全一致。阶段是**用户标注**，不是应用替考试院下结论。

## 三、判分契约（本版的保守口径）

| 题型 | 判分 | 说明 |
| --- | --- | --- |
| 单选/判断 | 自动精确 | 一个正确下标；判断用“正确/错误”原文 |
| 多选 | 自动集合 | **集合完全相等才算对**；部分分只展示，不进 FSRS |
| 填空/计算 | 自动规范化 + 自评回退 | 全角/空白/大小写/末尾标点归一；多个可接受答案；不命中给参考答案并让用户自评 |
| 简答/主观/材料 | 只自评 | 参考答案 + 评分要点；绝不自动判分 |

- 同一个 MULTIPLE 在不同考试规则不同：2025 新高考数学多选部分对部分分、有错 0 分；考研政治少选/错选均 0 分。
  本版不冒充任一规则，统一按“全对才算”判定；部分分只做反馈。
- **自评不写 review_log**：填空回退、简答、主观、材料只写 `practice_records`，不进 FSRS 校准流。
  避免把“用户宽容”学成记忆强度。
- 计算题只做最终答案的字符串规范化；不做符号等价/CAS，也不做数值容差。

## 四、数据模型与迁移

- `questions` v10 已有 `question_type` / `answer_indices_json` / `answer_text_json`；
  v11 新增 `exam_stage TEXT NOT NULL DEFAULT ''`（空串=未标注）与
  `(exam_stage, question_type, subject)` 复合索引。
- `ExamStage`：初中/高中/大学/考研/考公/未标注；不建独立表（与题一对一、无属性）。
- `QuestionType` 扩到 8 值：单选/多选/判断/填空/计算/简答/主观/材料。
- `GradingMode` 由题型纯派生：AUTO_KEYED / AUTO_NORMALIZED / SELF_RUBRIC，不落库。
- 旧题：`single` + 空阶段；不猜阶段。`Migration9To10Test`、`Migration10To11Test` 逐字校验。

## 五、导入与筛选

前缀：`[阶段·学科·题型]`（`·` 或 `/` 分段；1 段=题型，2 段=阶段+题型，3 段=阶段+学科+题型）。

```
[高中·数学·单选] 题干|A|B|C|D|B
[初中·数学·多选] 题干|A|B|C|D|AC
[初中·物理·判断] 题干|正确|解析
[高中·英语·填空] 题干|答案1;答案2|解析
[考研·数学一·计算] 题干|5/6;0.8333|解析
[考研·政治·简答] 题干|参考答案|评分要点|解析
[考公·申论·主观] 题干/材料|参考答案|评分要点
```

- 旧 `[单选]` 与无前缀行完全不变；无法识别的前缀进“待修正”（UNKNOWN_PREFIX），不把方括号当题干。
- 学科入口两行 chips：阶段 + 题型；不级联；学科卡显示当前组合题数；综合练习在 ≥2 科时出现。
- 模考只收单选/判断（单下标可编码）；多选/填空/计算/简答/主观/材料不进模考。
- 错题列表本轮不加阶段筛选；详情按文本展示，重做阶段遮住“正确答案/参考答案”之后的内容。

## 六、诚实边界

- **不内置任何题库**：国家智慧教育平台资源“不得用于商业行为”；高考/考研/国考真题与解析有版权；
  C-Eval/CMMLU 是 CC BY-NC-SA。应用只做元数据、筛选、用户本地导入与原创样题。
- 未支持匹配题/七选五/翻译；考研英语的新题型与翻译本轮落不下。
- 多选部分分不进 FSRS；不冒充各考试真实评分细则。
- 计算题不做符号等价/CAS/数值容差。
- 统计不做阶段正确率（旧 practice_records 没有阶段/题型列，主观题正确率又是自评）。
- 真机待验：v9→v11 覆盖安装、三种客观题 + 三种主观题的作答/自评/错题回归。
