> Android-приложение для управления учёбой с полностью локальным хранением данных: карточки слов / тесты, трекинг привычек, читательские заметки и работа над ошибками — четыре основных модуля плюс улучшенный календарный вид, при этом все данные хранятся на вашем собственном телефоне.

## ✨ О приложении

StudyKit — это универсальный помощник в учёбе для школьников, студентов и самоучек, построенный на дизайн-системе v2: токены двойной темы «тёплая бумага» (цвета, типографика и анимации выдаются из `ui/theme` и `ui/motion`), которая заменила минималистичные iOS-подобные токены единой светлой темы версии v1. **Учебные данные полностью локальны**: слова, отметки, контракты и ошибки хранятся в базе данных Room на вашем телефоне — ничего не отправляется, не синхронизируется, системы аккаунтов нет. Сеть нужна ровно для двух вещей, и обе можно не использовать: загрузка сторонних списков слов по HTTPS в «Онлайн-словарях» и одна проверка наличия новой версии при запуске.

- Дневная и ночная темы плюс плавная интерактивная анимация с высокой частотой кадров: светлая «тёплая бумага» и тёмный «тёплый чёрный» переключаются автоматически вместе с системой, а переворот карточек, отметки и подведение итогов идут на spring-анимациях, покадрово следующим частоте обновления 90/120 Гц

## 📦 Четыре основных модуля

### 📚 Модуль учёбы (слова / тесты)
- **Карточки слов**: режим обучения с переворачивающимися карточками — на лицевой стороне слово, на обороте определение; после переворота вы оцениваете себя по трём уровням — «помню / смутно помню / забыл» — а степень усвоения учитывается автоматически. Режим «сначала вспомни, потом оцени» включён по умолчанию: пока ответ не показан, свайп только переворачивает карточку и не выставляет оценку (можно отключить в настройках)
- **Тесты**: режим тренировки с вопросами с вариантами ответов, мгновенной проверкой и разбором ответов; ошибочные ответы автоматически попадают в тетрадь ошибок
- **Главная страница учёбы**: обзор сегодняшнего прогресса и накопленная статистика занятий

### ✅ Модуль трекинга привычек
- **Управление привычками**: создание привычек (название, периодичность, целевое количество) с подсчётом выполнений
- **Календарь отметок**: просмотр истории отметок по месяцам с возможностью отметить пропущенный день задним числом
- **Напоминания**: ежедневные напоминания об отметках через WorkManager + уведомления (взаимодействие отметок и подсчёта вдохновлено приложением «小计划»)

### 📖 Модуль читательских заметок
- **Управление книжной полкой**: добавление книг (название, автор, обложка, общее число страниц); обложки можно выбирать из локальных изображений (загрузка через Coil)
- **Прогресс чтения**: запись текущей страницы с автоматическим подсчётом процента прочитанного
- **Заметки**: архивирование читательских заметок по книгам с просмотром списка заметок для каждой книги

### ❌ Модуль работы над ошибками
- **Сбор ошибок**: автоматический сбор из тестов, а также ручное добавление (вопрос, мой ответ, правильный ответ, разбор)
- **Детали ошибки**: просмотр полной информации о вопросе и разбора, отметка «усвоено»
- **Экспорт и обмен**: тетрадь ошибок можно экспортировать в текстовый файл для удобной печати и повторения (улучшенная функция)

### 📅 Улучшенный календарь
- Глобальный календарный вид, объединяющий учебные задания, отметки привычек и записи о чтении
- Просмотр детальной разбивки всех учебных событий за любой день

## ⚡ Пакетный ввод (новое в v2.1)

Ручной ввод по одной записи был самой отталкивающей частью приложения, поэтому в v2.1
добавлена пакетная загрузка:

| Точка входа | Как | Примечание |
| --- | --- | --- |
| Вставка из буфера | Список слов / база заданий → «Пакетный импорт» | Одна запись на строку; распознаются табуляция, запятые, двойные и одиночные пробелы, третий столбец — пример (необязательно) |
| Файл | Там же → «Выбрать файл» | txt / csv и подобное; BOM и CRLF обрабатываются, парсеры те же, что и при вставке |
| Онлайн-словари | Список слов → «Словари» | 81 общедоступный список, поиск, прогресс загрузки для каждого; импортированный список можно **отменить целиком** |
| Скриншот → слова | Список слов → «Скриншот в слова» | Выберите скриншот «одно слово в строке», OCR попадёт сразу на экран предпросмотра |
| Фото с распознаванием | Ошибки → съёмка → «Извлечь текст из фото» | Первая строка становится заголовком, остальные — заметкой; **всё можно отредактировать**, автоматически ничего не сохраняется |

Все четыре источника проходят через один путь «предпросмотр → импорт → результат»: на предпросмотре
строки можно отмечать для исключения, битые строки попадают в блок «требует правки» с указанием причины,
и **ни одна строка не теряется молча**.
Распознавание текста — встроенная китайская модель ML Kit: **полностью офлайн, Google Play Services не нужны**
(работает на устройствах без GMS, например vivo).

Данные словарей взяты из открытого репозитория [kajweb/dict](https://github.com/kajweb/dict)
и предназначены только для личного обучения; после импорта всё работает офлайн, приложение ничего не отправляет.

## 🛠 Технологический стек

| Технология | Назначение |
| --- | --- |
| Kotlin | Язык разработки |
| Jetpack Compose + Material3 | Декларативный UI |
| Room | Локальная база данных (учебные планы, привычки, книги, ошибки и другие сущности) |
| Navigation Compose | Нижняя навигация и маршрутизация экранов |
| WorkManager | Задачи напоминаний об отметках по расписанию |
| Coil | Загрузка изображений обложек |
| ML Kit text-recognition (Chinese, bundled) | Офлайн-распознавание текста на скриншотах и фото; нативные библиотеки оставлены только для ARM-ABI, APK ≈ 33,7 МБ |
| androidx.profileinstaller + рукописный baseline profile | AOT-прекомпиляция цепочки запуска и горячих путей первого кадра на этапе установки (правила — `app/src/main/baseline-prof.txt`; CI-job сборки release проверяет, что они упакованы в APK как `assets/dexopt/baseline.prof*`) |
| Kotlin Coroutines + StateFlow | Асинхронность на корутинах и реактивное управление состоянием (в приложении нет хранилища настроек — всё состояние UI управляется через StateFlow) |

Среда сборки: JDK 17+ / Gradle 8.11 / AGP 8.7.3, `compileSdk 35`, `minSdk 26`.

## 🚀 Сборка и установка

### Требования
- JDK 17 или выше
- Android SDK (compileSdk 35)
- Реальное устройство / эмулятор с Android 8.0 (API 26) или выше

### Сборка
```powershell
# Windows
.\gradlew.bat assembleDebug
```
```bash
# macOS / Linux
./gradlew assembleDebug
```

Результат сборки находится в `app/build/outputs/apk/debug/app-debug.apk`.

### Установка на устройство
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

## 🚦 Что вы увидите при первом запуске

1. **Отказ от ответственности (принять обязательно)**: в нём прямо перечислены реальные границы приложения —
   данные только на этом устройстве, при удалении или очистке данных они пропадут,
   онлайн-словари берутся со стороннего зеркала, распознавание слов со скриншота не гарантирует
   правильного результата, а напоминания могут задерживаться политикой энергосбережения.
   Кнопка «Не согласен и выйти» сразу закрывает приложение. **У этого текста есть номер версии**:
   если условия изменятся, согласие спросят заново.
2. **Онбординг, шесть экранов (можно пропустить)**: первый экран — инструкция «Начните здесь» из трёх шагов
   (① загрузить слова, ② создать привычку, ③ подписать контракт, если хочется себя подтолкнуть), далее
   учёба / привычки / контракты / чтение и ошибки / данные — по три строки о том, что умеет этот модуль.
3. **Всё это можно посмотреть в любой момент**: в «Настройки → О приложении и поддержке» есть **обучение**
   (тот же материал, что и в онбординге при первом запуске), **отказ от ответственности**, ссылка на
   **репозиторий с исходным кодом**, а также текущая версия и «Проверить обновления».

> При запуске приложение один раз тихо проверяет новую версию: читается **API тегов репозитория на Gitee**
> (не GitHub — из материкового Китая он нестабилен). Если найдена версия новее, приложение попросит сначала
> обновиться, а «Перейти к загрузке» открывает страницу **Quark Netdisk**;
> **если номер версии получить не удалось, вас всегда пропускают** — отсутствие сети, ограничение запросов
> и ошибка разбора считаются отсутствием обновления, так что один сбой сети никого не оставит без доступа.
