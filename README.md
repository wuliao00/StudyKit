## ✨ 应用简介

StudyKit 是一款面向学生和自学者的一站式学习助手，设计语言为 v2 的「暖纸感」双主题令牌体系（配色、排版、动效统一由 `ui/theme` 与 `ui/motion` 下发），已不再沿用 v1 的 iOS 风格单主题极简令牌。**学习数据完全本地**：单词、打卡、契约、错题全部写在手机上的 Room 数据库里，不上传、不同步、没有账号体系。需要联网的只有两件事，且都可以不用：「在线词库」下载第三方词表、以及启动时查一次有没有新版本。

- 日/夜双主题与高帧率交互动效：浅色暖纸 / 夜间暖黑两套令牌随系统自动切换，翻卡、打卡、结算全程 spring 驱动，逐帧跟随 90/120Hz 刷新率

## 📦 五大功能模块

### 📚 学习模块（背单词 / 刷题）
- **单词卡片**：翻卡学习模式，正面展示单词、背面显示释义，翻面后自评「认识 / 模糊 / 忘记」三档，自动记录掌握状态。默认开启「先回忆再评分」—— 答案还没露出来时，滑动只帮你翻面、不算评分（设置里可关）
- **题库练习**：选择题刷题模式，即时判分与答案解析，错题自动归入错题本。多学科时默认**交错**打散（单学科不硬打散）；作答前可逐档要**提示**（线索 → 第一步 → 方法方向，三档都不给答案），答错才摊开完整解析；反馈分任务级 / 过程级 / 自我调节级三层。v3.5 起每轮 10 题**优先出最久没练过的**：练完一轮这批题就沉到队尾，下一轮自然轮到后面的题，60 道的题包不会被同一批 10 道堵住
- **学习首页**：今日学习进度、累计学习统计一览；另有「明天预计复习 N 词 · 到时候大约还记得 X%」的记忆看板
- **记忆引擎（排期内核）**：默认 FSRS v6（21 参数），翻面评分后由它排出下一次复习；可选手动切回半衰期旧内核（仅维护）。v2.9.0 起可选**端侧个性化校准**——用你自己的复习记录把这 21 个参数重训一遍，过硬/软门槛才换核。**校准全程在本机完成、记录不出设备**；后台只在**充电 + 空闲**时干跑出报告（不自动换核），是否采用新曲线由你在「设置 → 排期内核」里点
- **科学小贴士**：在对应时刻（首次高置信答错、漏一天、连续 21 天、新词第一次露面…）给一句反直觉但站得住的结论，每条附证据来源并以 `[科学验证]` 徽标呈现；事件对不上就不提示

### ✅ 习惯打卡模块
- **习惯管理**：创建习惯（名称、频率、目标次数），支持已完成次数计数；目标天数默认 66 天（习惯自动化研究中位数，不是「21 天」）
- **打卡日历**：按月份查看打卡历史，过往日期补卡支持；列表与详情并列「连续天数」与「近 7 天 x/7」双指标，漏一天只算 6/7 不等于破功
- **完成提醒**：通过 WorkManager + 通知提醒每日打卡（借鉴「小计划」的补卡与计数交互）

### 📖 读书笔记模块
- **书架管理**：添加书目（书名、作者、封面图、总页数），封面支持本地图片选择（Coil 加载）
- **阅读进度**：记录当前页码，自动计算阅读百分比
- **笔记记录**：按书目归档读书笔记，支持书内笔记列表查看

### ❌ 错题整理模块
- **错题收集**：从题库练习自动收集，也支持手动添加（题目、我的答案、正确答案、解析）
- **错题详情**：默认**遮住答案与解析**，先自己重做一遍再对照（检索练习优于再看一遍解析）；展开后信息零丢失，并给一条三问式自我解释提示；复习时间仍由你自己定
- **导出分享**：错题本可导出为文本文件，方便打印复习（借鉴改进功能）

### 🧭 学习设计模块（v3.4）
- **8 种模板**：费曼学习、习题带练、学会学习、互动工作坊、系列课规划、逆向教学设计、核心素养备课、螺旋式课程设计
- **结构化生成**：每种模板有独立字段与实时 Markdown 预览；填什么写什么，不调用模型、断网可用
- **可带走**：方案存本地，可继续编辑、整份复制、系统分享；转屏/进程回收后草稿不丢
- **依据可查**：每张模板卡写明方法论出处（费曼技巧、波利亚四阶段、Dunlosky 2013、Kolb、Wiggins & McTighe、核心素养、Bruner），不写没有落点的“研究表明”

### 📅 日历增强
- 全局日历视图聚合展示学习任务、习惯打卡与阅读记录
- 支持按日查看当天所有学习事件的明细

## ⚡ 批量录入（v2.1 新增）

逐条手打是这个应用最劝人的地方，所以 v2.1 把「加一条」改成「倒一批」：

| 入口 | 怎么用 | 说明 |
| --- | --- | --- |
| 批量粘贴 | 单词库 / 题库 →「批量导入」→ 贴文本 | 一行一条；Tab、逗号、两个空格、单空格四种分列自动识别，第三列可选作例句 |
| 文件导入 | 同上页面 →「选文件」 | txt / md / csv / docx / pdf；中文旧编码、Word 段落、PDF 文字层自动提取，扫描版 PDF 走端侧 OCR（前 20 页） |
| 题库商店 | 题库练习 →「题库商店 · 按阶段下载题包」 | 6 个原创题包共 332 题（每包 44~60 道），题包**在线优先**、缓存次之、内置兜底；卡片上标题型分布与本机已入库题数，逐包标来源与许可，下载后先预览再入库 |
| 链接导入 | 题库商店 →「从链接导入题包」 | 贴任意网站的题包文本地址（`https://…/包.txt`），不用对方提供目录，下载后同样先预览再入库 |
| 示例题库 | 批量录入题目 →「示例题库」 | 38 道原创题，覆盖 6 个阶段与 8 种题型；可自由修改，不包含真题 |
| 在线词库 | 单词库 →「词库」 | 81 本公开词表可搜可下载，带进度；导入后成为一本可**整本撤销**的词库 |
| 截图取词 | 单词库 →「截图取词」 | 选一张「一行一词」的截图，OCR 后直接进预览 |
| 拍照识别 | 错题本 → 拍照录入 →「从图片提取文字」 | 首行当标题、其余进备注，**仍可编辑**，不自动保存 |
| 拍照/相册录题 | 学习 / 题库 →「＋录入」→「拍照 / 相册录题」；错题本 →「拍照 / 相册」 | 现拍或从系统相册选一页题 → OCR；题库解析出条目就进预览，没分列就进编辑页，**不自动切错题本**；相册不需要存储权限 |

v2.7.0.1 起，学习首页与题库屏右上角那颗「＋录入」扩成了一个下拉菜单（录入单词 / 拍照 / 相册录题 / 批量录入题目 / 从词库导入）。
**已有的入口不重复摆**：单词库、错题本、书架不再加菜单（摘录批量入库在 schema 上还落不下，原因见 CHANGELOG）。

这几条来源共用同一套「预览 → 导入 → 结果」：预览页逐行可勾选剔除，坏行进「待修正」区并说明原因，
**不会静默丢行**；结果页给出成功 / 重复跳过 / 待修正，后两类都能展开看逐条明细。
OCR 自 v2.8.0 起用 **PP-OCRv6**（经 ONNX Runtime Android 推理，模型 Apache-2.0），**全离线、不需要 Google 服务**（vivo 等无 GMS 机型可直接用）；此前用的 ML Kit bundled 中文模型（2024-08 后停更）已下线。真机对拍显示 PP-OCRv6 字级错误率约为 ML Kit 的一半（CER 0.106 vs 0.210），代价是更慢与包体增大（双 ABI 约 +56MB）。

> v3.6 起两个模型（检测 9.5 MB + 识别 20.3 MB）可以不在 APK 里：把 `app/src/main/assets/models/`
> 下的两个 `*_ppocrv6_small.onnx` 挪出去再 `assembleDebug`，精简包小 25.5 MB（94.3 MB vs 121.2 MB）。
> 首次识别前到「设置 → OCR 模型」下载（下载后本机运行、不上传）。默认构建仍内置，断网即用。
> 识别失败（缺库/内存不足/模型异常/模型未下载）都会降级为一条错误提示而非崩溃。

词表数据来自开源仓库 [kajweb/dict](https://github.com/kajweb/dict)，仅用于个人学习；导入后完全离线，本应用不上传任何数据。

## 🛠 技术栈

| 技术 | 用途 |
| --- | --- |
| Kotlin | 开发语言 |
| Jetpack Compose + Material3 | 声明式 UI |
| Room | 本地数据库（学习计划、习惯、书籍、错题等实体） |
| Navigation Compose | 底部导航与页面路由 |
| WorkManager | 定时打卡提醒任务 |
| Coil | 封面图片加载 |
| ONNX Runtime Android + PP-OCRv6 | 截图 / 拍照离线 OCR（v2.8.0 起取代 ML Kit）；保留 ARM 两个 ABI，debug APK 约 90MB |
| androidx.profileinstaller + 手写 baseline profile | 安装期预编译启动链与首帧热路径（规则见 `app/src/main/baseline-prof.txt`，CI 的 release job 断言其已编入 APK 的 `assets/dexopt/baseline.prof*`） |
| Kotlin Coroutines + StateFlow | 协程异步与响应式状态管理（应用无偏好设置存储，全部 UI 状态由 StateFlow 驱动） |

构建环境：JDK 17+ / Gradle 8.11 / AGP 8.7.3，`compileSdk 35`、`minSdk 26`。

## 🚀 构建与安装

- JDK 17 或更高
- Android SDK（compileSdk 35）
- Android 8.0（API 26）及以上真机 / 模拟器

### 构建
```powershell
# Windows
.\gradlew.bat assembleDebug
```
```bash
# macOS / Linux
./gradlew assembleDebug
```

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

## 🚦 首次启动会看到什么

1. **免责声明（必须同意）**：写明这个应用真实存在的边界 —— 数据只在本机、卸载或清除数据会丢、
   在线词库来自第三方镜像、截图取词不保证正确、提醒可能被省电策略延迟。
   点「不同意并退出」会直接退出应用。**这份声明带版本号**：以后改条款会再征求一次同意。
2. **六页引导（可跳过）**：第一页是「从这里开始」三步（① 先把词装进来 ② 再建一个习惯
   ③ 想逼自己一把就签一份契约），之后是学习 / 习惯 / 自我契约 / 读书与错题 / 数据，
   每页三行讲清那个模块能做什么。
3. **之后随时可回看**：「设置 → 关于与支持」里有**使用教程**（与首启引导同一份内容）、
   **免责声明**、**源码仓库**入口，以及当前版本与「检查更新」。

> 启动时会静默检查一次新版本：读的是 **Gitee 仓库的 tags 接口**（不读 GitHub，那边国内直连不稳）。
> 检测到更新的版本会要求先更新再使用，「去下载」打开的是 **Gitee Releases** 页
> （发行版附件是 `.7z`，解压后安装；Gitee 单附件上限 100M）；
> **取不到版本号一律放行** —— 没网、被限流、解析失败都当作"无需升级"，
> 不会因为一次网络抖动把人锁在门外。

### v3.3.0：题库阶段 × 题型 × 判分方式

  旧 `[单选]` 与无前缀格式保持兼容。
- **边界**：模考只收单选/判断；匹配题/七选五/翻译未支持；计算题不做符号等价/CAS；
  错题列表本轮不加阶段筛选。逐条见 `CHANGELOG.md` 的 `[3.3.0]` 段与
